# R13: 실패 종목 사전 구분을 위한 단일 거래량 필터 (RESEARCH_ONLY)

## 질문과 한 번의 종료 규칙

**R5 추세선 돌파 신호에서 당일 거래량이 직전 20거래일 평균 이상인 사건만 남기면, 손절(-5%)보다 익절(+10%)에 먼저 도달하는 확률과 비용 차감 순수익이 유리해지는가?**

이 질문 하나만 검증합니다. R12 성공/실패 신호일 특성을 이미 살펴본 뒤 정한 *개발 표본상의 가설*이므로, 같은 5종목에 적용한 R13은 **새로운 독립 검증이 아니며 성공해도 실전에 사용할 근거가 되지 않습니다.**

### 고정 연구 조건

- 사용 데이터/신호: R12가 SHA 고정하고 재현한 R5/R116 과거 활성 저항선 돌파, 기존 원본 3종목과 보조 2종목은 분리해서 보고.
- 지표는 신호일(D0) 장마감에 알 수 있는 `d0_volume_vs_pre20` 한 개만 사용하며 **값이 1.0 이상**일 때 통과. 20일 평균·현재 거래량은 R5 원본 피처 그대로 사용. 값 누락은 불합격. 임계값 탐색/그리드/가중치 학습 금지.
- 순서: 모든 고유 종목·일자 신호 → 필터 적용 → 기존 R7 종목별 20거래일 embargo → D+1 시가 진입 → 최대 D+20 기간 중 `+10% 익절/-5% 손절` 고정 모델. 반대편을 같은 날 터치하면 보수적 손절 우선, 손절가보다 아래로 갭 하락하면 실제 그날 시가로 청산, 왕복비용 0.2%.
- 같은 순서에서 필터 없는 비중복 집단을 기준으로 함께 산출. 필터 적용 후 첫 신호일이 달라지므로 단순 평균 차이를 독립적인 필터 인과 효과로 주장하지 않음.
- 단일 필터를 적용한 양쪽 코호트 중 한쪽이라도 순기대수익이 0 이하이면 `REJECT_AS_A_PROFITABLE_ENTRY_SCREEN`으로 끝냄. 비슷한 임계값이나 다른 조건을 덧붙여 이 결과를 구제하지 않음.
