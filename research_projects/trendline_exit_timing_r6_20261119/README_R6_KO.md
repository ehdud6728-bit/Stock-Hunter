# Stock-Hunter R6 — 최고 상승 시점과 실행 가능한 매도 규칙 예비 연구

연구일: 2026-11-19 · **RESEARCH_ONLY** · 3종목 한정 후향적 설명 연구 · OOS/실전 규칙 아님.

## 목적: 최고점을 '알았던' 것처럼 파는 오류를 막는다

R5에서 D+1 시가 매수가부터 D+20 종가 수익률을 구했지만, **D+20 이전에 최고 몇 % 상승했는지와 그 가격을 언제 기록했는지**를 따로 봐야 한다. 다만 이 최고가(MFE)는 **이미 지나간 뒤에만 알 수 있는 EXPOST 수치**이다. 이를 실제 매도 가능 수익이라고 주장하지 않는다. R6은 두 개를 분리한다.

1. **사후 기회 설명**: D+1~D+20 최고 일중 고가, 최고일(D+1~D+20), D+20까지 이익 반납폭(퍼센트포인트), 최고일 이전 종가 기준 최대 눌림, +5/+10/+15% 최초 고가 터치일.
2. **미리 정한 실행 규칙**: 날짜별 고정청산, 고정 목표 익절, 전일 **완성된 봉의 고가까지** 반영한 추적손절, 목표·추적손절 병행, 동일한 고정 추세선 재이탈 **다음 날 시가** 청산.

## 원천과 분모

- R5와 같은 3개 종목(삼성SDI 006400, 디오 039840, 롯데하이마트 071840)의 고정 KRX 원본. R5 코드 SHA-256, 기존 R111/R116 알고리즘과 원본 CSV SHA-256 불일치 시 실패한다.
- 돌파선 단위 신호 **506건**, 고유 **종목·D0 날짜 368개**. 동일 거래일에 SHORT/MEDIUM/LONG이 중복되므로 **성과 표는 날짜당 한 사건만 채택**한다. 선택 우선순위는 성과와 무관하게 **MEDIUM → LONG → SHORT**로 미리 고정한다.
- 선택된 고유 종목·날짜 **368개 중 D+20 전체 경로 363개**, 나머지 5개는 미래 가격 부족으로 **미상** 처리. 선 단위 전체 506개 중 500개 완비.
- 실현 수익률은 모두 **D+1 시가 진입부터 익절·손절·시간청산 시점까지**, 왕복 총비용 **20bp(0.2%p)**를 차감한 단순 가상 수익률이다.

## 실행 규칙의 정의 (결과에 맞춰 변경 금지)

| 사전 고정 연구 모형 | 실행 원칙 | 미해결 위험 |
| --- | --- | --- |
| TIME_D5/10/20 | D+5/10/20 종가를 청산 가격으로 가정 | 마감가 주문 체결/슬리피지 미반영 |
| TARGET_5/10/15 | 진입가 대비 +5/+10/+15% 목표가에 고가 도달 시 그 목표가에 매도 가정. 아니면 D+20 종가 | 지정가 주문·체결 물량 미확인 |
| TRAIL_5/8/10 | 전일까지의 최고 고가와 진입가 중 큰 값에서 5/8/10% 하락하면 손절; 오늘 고가는 **내일**부터 반영 | 일중 고저 순서·실제 스톱체결 미확인 |
| TARGET_10_TRAIL_8, TARGET_15_TRAIL_8 | 목표가와 8% 추적손절을 동시에 적용 | 같은 일봉에서 둘 다 닿았다면 **손절 먼저** 처리, 해당 건은 모호성 기록 |
| LINE_RELOSS_NEXT_OPEN | 돌파 당시 확정된 **같은 선** 아래 종가 재이탈(0.4% 허용 버퍼) 시 다음 거래일 시가 청산. 아니면 D+20 종가 | 선 기하값이 부족한 사건은 결과 **미상**, 종가 관측 후 당일 청산 금지 |

추적손절 가격 아래로 시가가 갭 하락하면 **손절선이 아닌 더 불리한 시가**에 체결된 것으로 가정한다. 목표가 위로 갭 상승해도 우호적 시가 대신 **보수적으로 목표가**에 체결한 것으로 가정한다. 같은 날 고가와 저가가 모두 목표·손절을 충족하면 어느 순서인지 일봉으로 모르므로 **손절 우선**, 모호성 플래그를 남긴다. 이 규칙은 1분봉/체결자료가 없는 상태의 **단순 연구 가정**이지 실제 주문 체결 재현이 아니다.

이 수치는 **전체시장 성과가 아니며 비교 모형 중 우월한 매도 규칙을 찾아냈다는 의미가 아니다.** 이미 관찰된 3종목 표본은 편향되어 있고, 같은 종목의 여러 돌파일도 시장 움직임을 공유한다. 시간 청산과 목표 청산의 평균 차이는 표본 우연, 모형의 체결 가정 또는 거래 비용에 영향을 받을 수 있다.

특히 `LINE_RELOSS_NEXT_OPEN`은 **4개 사건에서 원본 선의 사후 기울기 정보가 부족**하므로 D+20 경로가 완비된 363개 중 **359개만 계산**, 4개는 미상이다. 누락을 0% 수익률로 채우지 않는다.

## 검증 방법

저장소 루트에서 `numpy`, `pandas` 설치 후:

```bash
python -m unittest discover -s research_projects/trendline_exit_timing_r6_20261119 -p 'test_*.py' -v
python research_projects/trendline_exit_timing_r6_20261119/r6_exit_timing.py \
  --repo . --out reports/trendline_r6
```

출력:

- `R6_EXIT_TIMING_SUMMARY.json`: 최고 시점 분포, 12개 모형 평균/중앙/하위 10%/극단값 한 건 제외 평균·모호성 등.
- `R6_EXIT_TIMING_FULL_AUDIT.json`: 506개 개별 추세선 사건과 가상 매도 경로 원장.
- `R6_PRIMARY_STOCK_DATE_EXIT_RULES.csv`: 중복 날짜를 1건으로 고정한 사건 × 12개 매도 시나리오(미상 포함) 표.

단위 테스트는 미래 최고점이 매도 규칙에 섞이지 않는지, 사전 완성된 봉만으로 추적손절을 계산하는지, 갭과 하루 두 조건 충돌 시 보수적으로 계산하는지, 동일 추세선 이탈을 익일 시가에 체결하는지 검증한다. R5 D+20/MFE 결과와 R6 산출값의 일치를 확인한다.
