# R1-D103 | 이평선별 역할·패턴 연구 (RESEARCH_ONLY)

## 목적
224일선 아래를 필수 조건으로 사용하지 않고, 5·20·60·112·224일선의 **당시** 위치와 가격 상호작용을 분리하여 어떤 상황에 어떤 이평선이 유용했는지를 사후 기술통계로 비교한다. 3·10·30·40·120·240·448·480일선의 가격 이격도/기울기 등 기존 13개 이동평균선 자료도 이벤트 이전 스냅샷에 보존한다.

### 연구를 위해 미리 지정한 역할 가설 (검증 결과가 아님)
| MA | 역할 가설 | 검사할 질문 |
|---|---|---|
| 5 | 매우 단기 추세 및 탄력 | 5일선 재돌파 또는 이탈 이후 5·20일 주가 반응은? |
| 20 | 눌림 및 단기 파동 | 20일선 재접촉 후 위에서 마감한 경우와 아래서 마감한 경우가 다른가? |
| 60 | 중기 파동 | 60일선 회복·상실이 추세 구조에 따라 달라지는가? |
| 112 | 중장기 변화 | 장기 이평선이 하락하는 동안 112일선 회복은 어떤 의미가 있었나? |
| 224 | 장기 국면 분류 | 224일선 위/아래는 거래 가능성의 제한 조건이 아니라 사후 비교용 구간인가? |

## 데이터·절차
1. R1-D97 해시 고정 3종목(디오/롯데하이마트/삼성SDI). R1-D101 `build_features`로 13개 MA·BB/ENV·거래량·거래대금 계산, R1-D102 구름대 추가.
2. 전체 후보 시점에서 5·20·60·112·224일선의 `RECLAIM_ABOVE`, `LOSE_BELOW`, `TOUCH_ABOVE_CANDIDATE`, `TOUCH_BELOW_CANDIDATE` 이벤트를 **미래 결과와 무관하게** 기록한다.
3. 이평선별 5/20일 기울기·기울기 변화, 종가 이격도, 5일간 이격 변화, 일목/이평 구름대 두께, BB20 폭, 거래대금/이전 20일 평균, 당시 고점·저점 추세 구조를 기록한다.
4. 연구용 과거 결과(D+5/D+20 종가, D+20 기준 SURGE/CONTROL/OTHER)를 **별도 함수**에서 병합한다. 이것은 매수·매도 신호가 아니다.
5. 같은 MA+이벤트 유형은 최소 20거래일 간격으로 기술통계 표본을 만든다. 여러 MA가 같은 날 이벤트를 발생하면 원본을 유지하고 `R1D103_SAME_DAY_OVERLAP_LEDGER.csv`에서 중복을 공개한다. 표본을 독립 매매로 계산하지 않는다.
6. 동일 상황에서도 장기 이평선이 모두 상승/하락/혼합인지, BB20이 확대·수축인지, 거래대금이 평균 이상/미만인지에 따라 분리해 비교한다.
7. 당시 5·20·60·112·224일선의 상태를 기존 3개 기준일과 직접 비교한다.
8. PIT 미래 가격 변조 테스트: 미래 주가를 변경해도 당시 지표·과거 이벤트는 불변이어야 한다.

## 주의사항
- 5/20/60/112/224일선의 용도는 사전 가설이며 통계적으로 검증된 우월성은 아니다.
- 고점·저점 방향과 이동평균선이 접촉한 시점의 관계는 상관관계이지 인과관계가 아니다. 마감 시점 MA는 해당 마감 종가를 포함하므로 장중 매매 신호로 재사용하면 안 된다.
- 3개 종목, 서로 겹치는 이벤트, 원시 KRX 조정주가 미검증: 수익률·실전 적용은 금지.
- R1-D96~102 / WATCH / LIVE / 실전 검색식은 변경하지 않는다. 새 워크플로를 생성하지 않고 기존 R1-D98 공통 YML을 한 번 덮어쓴다.

## GitHub 사용법
기존 `.github/workflows/stockhunter_r1d98_state_structure_research_only.yml` 파일을 ZIP의 **동일 경로**로 교체하고, 신규 `research_projects/r1d103/` 폴더를 추가한다. 새 워크플로 경로는 만들지 않는다. `Actions → StockHunter Trendline Research → Run workflow → study=r1d103`에서 실행. ZIP 루트에 동일 YML 사본도 있어 모바일에서 내용을 확인할 수 있다. 최종 성공은 GitHub Actions에서 실제 원본 데이터를 실행해야 확정된다.
