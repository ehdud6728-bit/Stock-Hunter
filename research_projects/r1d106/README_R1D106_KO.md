# R1-D106: 의미 있는 캔들 기준점·다중 추세선·삼각수렴 연구 (RESEARCH_ONLY)

## 무엇이 새로워졌나

**기존 R1-D96~D105 연구 코드를 변경하지 않습니다.** 새로운 독립 연구 영역에서 매 거래일 이미 알 수 있던 캔들·피벗을 이용합니다.

- 양봉 몸통 상단(BULL_BODY_TOP=종가), 양봉 몸통 하단(BULL_BODY_BOTTOM=시가)
- 음봉 몸통 하단(BEAR_BODY_BOTTOM=종가), 음봉 몸통 상단(BEAR_BODY_TOP=시가)
- 실제 고가/저가의 좌우 2봉 확정 피벗(WICK_HIGH_PIVOT2, WICK_LOW_PIVOT2)
- 동일 종류 기준점 두 개를 3~25거래일 간격으로 연결, 원본 전체 유지. 어떤 선도 사후 수익률을 보고 선택/삭제하지 않습니다.
- 양봉/음봉 후보: 몸통 ≥ 캔들 전체 폭의 25%, 양봉 종가 위치 ≥ 저가에서 64%, 음봉 종가 위치 ≤ 저가에서 36%. **시작 가설(결과에 맞춘 최적값 아님)**
- 각 선의 최초 작성 가능일·확정일·기준점·기울기·기준점 사이 관통 횟수 기록.
- 고점·저점 수렴 후보: 상단 상승폭이 하단 상승폭보다 작은 경우만, 두 선이 **동시에 알려진 날** 최초 판정. 교차 예정 시점은 기하학적 추정이며 매매 신호가 아닙니다.
- 모든 선 후보는 **불변 원본 카탈로그**에 보존; 활발한 사건 탐색에서는 두 번째 앵커가 40거래일 이내인 선만 검사하지만 이것은 이력 삭제/만료가 아닙니다.

## 검증 경계

1. **미래 데이터 오염 방지**: 양봉 몸통선은 종가에서, 피벗 고가·저가선은 피벗 발생 후 우측 두 거래일의 종가에서 알려집니다. 선의 이벤트는 반드시 그 선이 **전날 이미 알려졌을 때만** 기록됩니다.
2. **선별 편향 억제**: 후보는 당일 시점에서만 생성, 상승·실패 결과는 EXPOST 파일에서만 붙입니다. 5개 사례 중 2개는 사후 결과를 알고 선정한 **예시**이며 유효성 검증에 쓰면 안 됩니다.
3. **유용성/저평가 확정 금지**: 3종목의 역사적 기술지표, 기업가치나 실거래 수익성 검증이 아닙니다.
4. **캔들 기준의 편차**: 종가 기준 양봉 상단선은 실제 고가 저항선과 다릅니다. 추세선이 실제로 얼마 동안 가격에 존중됐는지는 별도 검증해야 합니다.
5. **원래 WATCH 및 LIVE 보호**: 기존 R1-D96~D105 원본/이력/실거래는 변경하지 않습니다. 기존 공유 YML 한 개만 수정합니다.
