# R25 | 55일 돌파의 +30% 상승 기회 포착과 실제 매도 수익 분리 검증

**RESEARCH_ONLY**. 기존 R19~R24, LIVE·SEARCH·WATCH, 실전 조건검색·매수/매도·주문·알림은 변경하지 않습니다.

## 목표

R24는 손실 위험 모델이 2024~25년에 평가한 59건 중 사후 +30% 상승 기회 20건 가운데 8건을 잘못 제외한 사례를 보여줬습니다. R25는 "손실 종목을 제거한다" 대신 다음 두 질문을 각각 측정합니다.

1. **사전 발견:** D0 종가까지 알 수 있는 정보만으로 향후 D+1 시가 대비 D+60 이내 장중 최고가 +30% 이상에 도달하는 종목을 몇 건 유지할 수 있을까?
2. **수익 실현:** 실제 사전에 정한 종가-익일시가 매도 규칙으로 그 상승 기회를 얼마나 실현할 수 있을까?

장중 최고가 +30%는 **EXPOST_ONLY 라벨**이며 결코 실현 수익률이나 보장되는 지정가 체결이 아닙니다. 개별 종목을 30% 오를 것이라고 확언하지 않습니다.

## 데이터 잠금과 비교 기준

- KIS 원본: BLUE 고정 실행 44988188271, 26종목 37,736 일봉. 기존 R16 해시 검증 실패 시 즉시 중단.
- 실제 원형: R19 진짜 55일 돌파 149건, D0 종가 신호, D+1 시가 진입, D+60 보유 최대.
- R20 MA5 및 R22 돌파 기준선 2일 연속 이탈 수익과 종목·일자·실현수익·청산일을 사건별 대조.
- 왕복 거래 비용 0.2%; D+60 관찰 종료일 종가 사용.
- 2023-09-29까지의 84건은 훈련, 2023년 4분기 6건은 60거래일 후행 라벨 겹침 위험을 줄이기 위해 제외, 2024~25년 59건은 후행 검토. **이미 앞선 연구에 노출된 기간이므로 무오염 OOS가 아님.**

## 사전 +30% 기회 탐색 모델

- 입력은 R24와 동일한 D0 확정 5가지 특징(종가 위치, 거래량/거래대금 대비 증가, 최근20일 상승률, 고점 돌파 폭)만 사용.
- 목적변수는 훈련 구간의 D+1~D+60 장중 최고가가 D+1 시가 대비 +30% 이상인지 여부.
- 미리 고정한 로지스틱 C=0.25; 결측 대체·표준화·모델·선별 경계는 오직 훈련 구간에서만 학습.
- 우선 +30% 상승 종목을 충분히 남기려는 의도로 **훈련 점수의 하위 25%만 제외할 수 있는 경계(25백분위)**를 고정. 검토 구간에서 실제 남는 종목 비율은 훈련과 다를 수 있음.
- 검토 구간에서 **전체선택(기본 포착률 100%)**과 **훈련 경계로 선별**을 비교. +30% 상승 기회 포착률(recall), 정확도(precision), 제외해버린 +30% 건수, 실제 보유 종목 비율, AUC/Brier, 원본 및 유지 집단의 동일 매도 수익을 모두 보고.
- 기존 R24 모델이 제외한 +30% 8건과 일치 재현하는지 확인. R24 위험 점수는 R25 모델의 입력으로 사용하지 않음.

## D+1 · D+3 · D+5 경로 진단

해당 날의 확정 종가가 D+1 원래 매수가보다 위인지, 55일 돌파 가격보다 위인지, 당일의 5일 이동평균 이상인지 살펴봅니다. 이는 각 날짜의 확정 장 종료 **이후에만** 판정할 수 있습니다.

이후 D+(k+1) 시가부터 D+60 장중 최고가까지의 상승 기회를 사후 비교합니다. 이것은 새 진입 가정의 상한 관찰이며 D+1 매수가로 쭉 보유한 수익률, D+1에 알 수 있는 정보, 기존 MA5로 이미 청산된 거래의 회복 이익과 혼동해서는 안 됩니다. D+1/3/5 진단은 **모델 선택/매도 전략의 입력으로 절대 사용하지 않습니다.**

## 사전에 결정한 매도 네 가지

| 매도 규칙 | 실제 체결 가정 |
| --- | --- |
| R20 5일선 첫 종가 이탈 | 다음 거래일 시가에 전량 정리. 원본 코드 재사용 |
| R22 55일 돌파선 아래 2일 연속 종가 이탈 | 다음 거래일 시가에 전량 정리. 원본 코드 재사용 |
| D0 저가 종가 이탈 또는 +30% 종가 도달 | 둘 중 먼저 발생한 종가 신호의 다음 시가에 전량 정리. 일중 +30% 고가만으로 팔지 않음 |
| +15% 종가 도달 후 절반 정리 + MA5 나머지 | +15% 종가 신호 다음 시가에 50% 정리, 나머지 50%는 MA5 종가 이탈 다음 시가에 정리. +15%와 MA5 신호가 같은 봉이면 MA5 전량 정리 우선 |

수익 계산은 50% 매도를 가중합하고 전체 왕복 비용 0.2%를 반영합니다. 매도 신호 이후 생긴 주가 상승은 수익에 가산하지 않습니다.

**보고 지표:** 각 매도 방식의 전체 149건 평균/중앙/하위10%/최악/승률/상위 1건 제외 평균, 사후 +30% 상승 기회 40건 중 실제로 순수익률 +15%/+30%를 실현한 건수, 최초 장중 +30% 도달 전 이미 청산된 건수, 순수익과 60일 사후 최고가 상승 폭의 비율. 후자는 설명용이며 최대 수익을 실제로 얻을 수 있었다는 뜻이 아닙니다.
