# R1-D101 — 상승 전 모든 주요 이평선·밴드·거래량의 선행 변화 분석

## 연구 질문

R1-D96~D100에서 진행한 고점·저점 추세선, 이동평균선, 볼린저밴드·엔벨로프 연구를 유지하면서
**상승이 확인된 종목과 오르지 못한 종목의 '상승 전 20거래일' 당시 자료**를 같이 비교한다.
상승 후의 정보를 입력 변수로 사용하는 것은 금지한다.

### 입력 원본

- R1-D97 동결 KRX 원시 일봉·거래대금: 디오(039840), 롯데하이마트(071840), 삼성SDI(006400).
- SHA256 3종목 검증, GitHub 공통 Workflow의 R1-D96/97 고정 소스 검증 유지.
- `dynamic_structure.py`(기존 R1-D100)의 확정 피벗 기반 고점/저점 연결선 사용.
- R1-D96~D100 소스, R1-D99 오래된 WATCH, 실전/LIVE 검색식은 절대 수정하지 않음.

### 이동평균선: **모든 설정 기간**

기본 연구 기간: **3, 5, 10, 20, 30, 40, 60, 112, 120, 224, 240, 448, 480일** (13개).
모든 기간을 개별적으로 추적: 값, 종가 이격도, 5/20일 기울기, 20일 기울기 가속도, 5일 이격 변화량.
모든 서로 다른 쌍의 이격도(13C2 = 78쌍)와 5/20일 이격도 변화량, 상향/하향 교차 기록.
기간은 `pre_rise.py`의 `MA_WINDOWS` 설정으로 변경할 수 있다. '모든'은 설정된 기간 전부를 의미하며 무한 개의 수학적 기간을 의미하지 않는다.

### 가격 밴드

- 볼린저밴드: 20/30/40일, 평균 ±2 표준편차(ddof=0). 상/하단과 중심, 상대 폭(%), 5/20일 폭 변동, 상/하단 기울기, 상/하단과의 거리, 120일 폭 백분위.
- 엔벨로프: 20/40일 SMA의 ±10% 상/하단. 상/하단 기울기, 절대 폭과 5일 변화, 주가와 상/하단 거리 기록.
- **엔벨로프 상대 폭은 수학적으로 항상 20%**이며 볼린저밴드 같은 수축·확장 지표로 쓰지 않는다.

### 거래량·거래대금

- 당일 거래량/거래대금 ÷ **전일까지의 20일 평균** (오늘을 분모에 포함하지 않음).
- 5/20일 평균 거래량·거래대금, 5일 평균 대비 전일 기준 20일 평균.
- 상승일 거래량·거래대금 비중, 20일 OBV 변화 근사치, 20일 가격 범위.
- 상승일 거래대금 비중은 **순매수·기관 수급 증거가 아니다**. 매수/매도 주체를 원시 일봉만으로 판별할 수 없음.

### 선행 시점과 결과의 엄격한 분리

- 관찰 변수(PIT): **D-20, D-10, D-5, D-1, D0**. 해당 시점 이후 가격이 변수에 들어가면 실패.
- 미래 결과 라벨은 별도의 OUTCOME 테이블: D0 종가 대비 앞으로 20거래일 내 고가 최대 +10% 이상, D+20 종가 +5% 이상이면 `SURGE`.
- `CONTROL`: 앞으로 20거래일 내 최고가가 +5% 이하, D+20 종가 수익률이 0% 이하.
- 나머지는 미분류로 보존하고, 고의로 제외됐다는 사실을 감사 데이터에 남김.
- **이 +10%/+5% 값은 연구용 사전 가정이며, 최적 매수 조건으로 튜닝한 값이 아님.** 임계값 변경 민감도 검증과 OOS 테스트는 후속 과제.
- D0 종가가 224일선 아래이고 480일선까지 관찰 가능할 만큼의 과거 기록이 있으며 D+20 결과 확인 가능한 모든 날짜를 후보 기록으로 남김.
- 동일 종목·동일 라벨은 20거래일 간격의 비중복 샘플(최대 8개/라벨)로 표시. **전체 모집단과 별도로 저장**하고 삭제하지 않음.
- **R1-D100 원래 기준일 3개는 별도 REFERENCE 사례로 반드시 포함**: 디오 2024-09-13, 롯데하이마트 2024-03-04, 삼성SDI 2024-02-07. REFERENCE는 SURGE/CONTROL 중앙값 계산에서 제외하며, 결과 라벨은 참고용으로 따로 기록.
- 진정한 `추세 전환`을 보장한 양성표본이 아님. 기준일과 D+20 고점·저점 구조 변화를 OUTCOME 전용 파일에 따로 기록하며, 성공 사례 중 전환을 동반한 하위 집단을 이후 검토.

- `R1D101_DEOVERLAPPED_CASES.csv`: 비교용 날짜와 SURGE/CONTROL 분류 + 별도 고정 REFERENCE 날짜.

- `R1D101_CASE_SUMMARY.csv`, `R1D101_PIT_TAMPER.csv`, `R1D101_AUDIT.json` 및 비교 차트.

### 중요한 제한

1. 이 단계는 **3종목 사례 연구이며 전체 시장/종목 외(OOS) 검증이 아니다**.
2. 미래 결과로 라벨링한 SURGE는 사후 연구 대상이지 실시간 탐지 신호가 아니다. 상승 후 어떤 지표가 달랐는지 비교하는 가설 생성용.
3. 동일 시장 국면, 업종, 시가총액, 변동성 등을 맞춘 엄밀한 대조군은 아직 아님.
4. 조정주가/액면분할 등 기업행위의 완전성은 미검증.
5. 다수 지표를 동시에 검토하므로 다중비교 및 선택 편향 위험이 크다. OOS와 독립 기간 반복 검증 전 최적 조건을 매매식에 반영하면 안 됨.
6. R1-D99 WATCH의 무기한 보존 정책 유지. 이번 연구는 새로운 데이터만 출력.
