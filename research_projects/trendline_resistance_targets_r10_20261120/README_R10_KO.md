# R10: 과거 매물대 후보 목표가 독립 검증 (RESEARCH_ONLY)

## 질문

영상의 설명에서 착안한 **과거 저항대 근처에서 목표가를 지정하면 D+20 보유보다 손실 분포가 나아지는가?**를 검증한다. 영상의 특정 차트나 목표 가격은 종목별 진입 시점에 소급해 적용하지 않는다. R5/R6의 3종목·506 선 신호·368 종목/일 대표 신호를 수정 없이 상속한다.

## 사전에 고정하는 규칙

| 구분 | 고정 조건 | 인식 시점 |
| --- | --- | --- |
| 공통 | D0 직전 120거래일만 사용. 계산된 목표가는 D0 종가 대비 최소 2% 위 | D0 종가 **후** |
| `PRIOR_PIVOT_120` | 좌 2일·우 2일 확인된 고점 두 개가 서로 1% 이내인 저항대. 가장 가까운 자격 있는 고점의 낮은 가격 사용 | D-1까지 |
| `DAILY_AMOUNT_HLC3_PROXY_120` | 과거 일별 거래대금 전부를 해당 일의 `(고가+저가+종가)/3` 한 가격 구간에 임의 귀속. 구간폭은 D0 종가의 2%, 최소 3일, 구간 누적 거래대금은 양수 구간 중앙값의 1.5배 이상. 가장 가까운 상단 구간의 **하단**을 목표가로 사용 | D-1까지 |
| 진입 | D+1 시가. 이미 고정 목표가 이상으로 갭 상승한 진입은 `UNKNOWN` | D+1 시가 |
| `TARGET_ONLY` | 목표가 지정가 청산, 도달하지 않으면 D+20 종가 | D+1~D+20 |
| `TARGET_ATR_INITIAL_3` | 목표가 지정가 + 진입가 − `3×D0 ATR14` 고정 손절, 미도달 시 D+20 종가 | D+1~D+20 |
| 체결 가정 | 목표가 갭 상승 시 지정가 청산 가격은 목표가로 보수적 제한. 손절 갭 하락 시 시가. 하루에 목표가와 손절가 동시 접촉하면 **손절 우선** | 일봉 한계 |
| 비용 | 왕복 합계 20bp(0.2%p). `TIME_D20`, `TARGET_5`, `TARGET_10` 및 기존 R7의 `ATR_INITIAL_3`와 **동일 신호**에서 짝지어 비교 | 공통 비교 |

**매우 중요한 제한:** 일봉 거래대금의 HLC3 귀속값은 실제 매물대(가격대별 거래량·거래대금)가 아니다. 체결 틱, 실제 가격대별 누적 거래량, 매수·매도 주도량 및 호가잔량은 추정할 수 없다. 따라서 `DAILY_AMOUNT_HLC3_PROXY_120` 결과를 실제 매물대 목표가 성능이라고 표현하면 안 된다.

## 편향 통제와 해석 범위

- 주식/신호를 추가하거나 특정 수익률에 맞춰 매개변수를 바꾸지 않는다. 목표가를 찾지 못하거나 과거 자료·ATR·D+20 경로가 부족하면 `UNKNOWN`으로 남긴다.
- 고정 목표가가 있는 표본과 없는 표본을 구분한다. 비교 수익률은 반드시 **같은 신호의 결과가 모두 존재하는 교집합**만 사용한다. 전체 368건 평균과 비교하지 않는다.
- 같은 종목의 20거래일 이내 겹침을 첫 신호부터 배제한 별도 비중복 결과를 제공한다. 이것 역시 3종목 파일럿이지 독립 OOS가 아니다.
- 특히 `목표가 + ATR`의 개선은 ATR 손절만으로도 발생할 수 있다. 따라서 **기존 R7 ATR 손절 단독 대비 추가 효과**를 별도로 확인하고, 영상에서 유래한 목표가 효과와 혼동하지 않는다.
- `R5`→`R6`→`R7` 원본 스크립트를 SHA256으로 고정·재사용한다. 원본 데이터 계보, 수정주가/원주가, 기업행동, KIS 소스 독립 검증(R9)은 아직 미인증이다.
- 차트 해석은 설명이 아니라 **검증 가설**이며 `strategy_winner=null`, 전략 전환·실거래 승격·실적 홍보·LIVE/SEARCH/WATCH 변경을 모두 금지한다.
