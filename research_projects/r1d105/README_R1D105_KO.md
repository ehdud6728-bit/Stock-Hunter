# R1-D105 — 추세선·이평선·BB·엔벨로프·구름대·거래대금 모든 사건 + 실제 5사례 연구

**RESEARCH_ONLY. LIVE·실전 검색식 변경 없음.**

## 목표

R1-D104 `EVENT_ONLY`는 이평선 이벤트를 기준으로 날짜를 뽑아, 추세선·BB·ENV 단독 사건이 빠졌다. R1-D105는 R1-D104의 전체 종목·날짜 PIT 기초 자료를 다시 생성한 뒤, 사건 탐지를 **이평선 이벤트와 독립적으로** 수행한다.

1. **전체 사건 보존**: 5·20·60·112·224일선 재돌파/이탈 및 기울기 0 통과; 단기/중기 고점·저점 추세선 갱신·기존 확인선 돌파/이탈; BB20/30/40 상하단 돌파·복귀, 폭 수축↔확대; ENV20/40 상하단 돌파·복귀 및 절대 폭 변화; 단기·중기·장기·전체 MA 구름 및 일목 구름의 위치·두께·높이 변화; 구조 변화; 거래대금의 이전20일 평균 상하 전환.
2. **사건 발생 날짜 통합**: 같은 종목·날짜에 N개 사건을 유지하면서 종목·날짜 기준으로는 한 번만 집계한다. 예: 이평선 이벤트 0건인 추세선 단독 사건도 그대로 포함한다.
3. **사건의 순서**: 20거래일 간격으로 먼저 관찰된 사건을 연구 앵커로 삼고, D-20~D+20 사건을 기록한다. D0 이전 `PIT_HISTORY`, D0 이후 `POST_EXPOST_ONLY`를 구분하며 미래 사건은 D0 판단에 이용하지 않는다.
4. **상승 전 상태**: 사건 기준 D-20·D-10·D-5·D-1·D0의 모든 PIT 기술 지표 스냅샷. R1-D104 734개 기준일 중 초기 20일 과거 자료는 원본 OHLCV에서 직접 재계산해 완성한다.
5. **실제 5사례**: 디오 2024-09-13 (실패), 롯데하이마트 2024-03-04 (실패), 삼성SDI 2024-02-07 (반등), 삼성SDI 2024-01-22 (급락 후 반등), 디오 2024-08-02 (계속 하락). 5개 차트와 날짜별 CSV·한글 상세 설명 생성.
6. **후행 성과는 분리**: D+20 종가/고가 결과는 사건을 모두 탐지·묶은 후 붙인다. 실전 매매 수익률·승률 검증이 아니라 서술적 분석이다.

## GitHub 실행

기존 `.github/workflows/stockhunter_r1d98_state_structure_research_only.yml` **파일을 교체**한다. 새로운 Workflow 파일을 만들지 않는다. Actions → 기존 `StockHunter R1-D98 / D99 / ...` → Run workflow → `study: r1d105`.

`r1d105` 단계가 **기존 R1-D104 연구기를 먼저 재실행**해 원본 KRX 입력 SHA256 검증과 동일한 전체 PIT 자료를 생성한 뒤, 전체 사건 통합과 5종목·날짜 사례 보고서를 만든다. 따라서 전체 실행은 R1-D104 단독보다 오래 걸린다. `all` 선택은 구버전 단독 실행과 R1-D105 내부 재생성을 모두 진행할 수 있으므로 연구는 `r1d105` 단독 선택을 권한다.

## 논리적 주의

- 같은 종목의 일별 사건을 독립 거래로 계산하지 않는다. 20거래일 앵커도 시장국면/종목 종속성을 없애지는 않는다.
- 상단·하단 추세선은 R1-D100 확정 피벗의 **그 날짜 PIT 선**이다. 새 피벗으로 그날 바뀐 선을 돌파한 것으로 오인하지 않는다.
- `ENV±10%`의 상대 폭은 수학적으로 20% 고정이며, 절대 폭 변화만 추적한다.
- R1-D104 산출물에서 계산한 **로컬 사례 연구 ZIP**과 GitHub에서 새로 실행될 R1-D105 artifact는 구분한다.
- 3종목, 미조정 KRX 과거 가격, 독립적 표본외 테스트 전: 조건검색식이나 LIVE에 반영하지 않는다.
