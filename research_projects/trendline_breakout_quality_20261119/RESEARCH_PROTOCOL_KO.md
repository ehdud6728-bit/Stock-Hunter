# 추세선·전고점 돌파의 과정 연구 — 사전 등록 프로토콜

상태: 설계만 등록. RESEARCH_ONLY. 결과 데이터 미생성. 기존 실전 검색식 변경 없음.

## 0단계 — 삼성SDI 동일 추세선 검증이 가장 먼저

- 대상: 삼성SDI의 2026-11-02 기준 추세선과 2026-11-06 돌파 판정에 사용된 선.
- 실제 일봉 차트에서 당시 확정된 두 앵커의 날짜/가격, 앵커가 D0 이전 시점에 확정되었는지, 선의 기울기와 기준점, 11월 2일과 11월 6일 선 가격을 고정한다.
- 11월 6일 계산에 다른 고점이나 미래 앵커를 사용했는지 별도 체크한다. 같지 않은 선을 돌파했다고 판정하면 원인을 분석하고 먼저 고친다.
- 현재 이 검증은 완료되지 않았다. 시각적 실차트 검증과 해당 알고리즘 코드의 동일선 ID가 필요하다.

## 돌파 사건의 종류를 먼저 구분

1. 추세선 종가 상향 돌파: D-1 종가는 그날 선 이하, D0 종가는 같은 고정선의 D0 값 초과.
2. 전고점 돌파: D0 이전에 확정된 전고점 레벨을 D0 종가가 넘음. 전고점 확정에는 D+ 자료를 쓰지 않는다.
3. 이동평균선 상향 돌파: 20/60/112/224일선 중 무엇인지 별도의 사건 종류로 표시.
4. 장중 관통 후 종가 미안착, 장 시작 갭 돌파, 종가 돌파를 구별한다.
5. ENV10/ENV20 하단 터치와는 별도 트랙으로 유지한다. 표본을 사후에 합쳐 승리하는 조합을 만들지 않는다.

## 돌파 당일 시점에 알 수 있는 특징

| 특성 그룹 | 원자료와 계산 |
| --- | --- |
| 장기 위치 | D0 종가 / D0 확정 MA20·60·112·224, 224일선 위/아래 위치 |
| 이전 파동·눌림 | D-1 이전 상승 구간과 눌림의 가격·기간, 이전 전고점/전저점의 시점과 거리 |
| 횡보·압축 | 직전 20/60거래일 고가·저가 범위, 범위 내 D-1 종가 위치 |
| 거래량 증가 | D0 거래량 / 직전 20개 거래일(D-20..D-1)의 평균 거래량 |
| 거래대금 증가 | D0 거래대금 / 직전 20개 거래일(D-20..D-1)의 평균 거래대금 |
| 거래량의 선행 축적 | D-20..D-1 유효 거래량 추세, 5/20일 평균 비율, 이상치·거래정지 |
| 돌파 강도 | 돌파선 대비 D0 종가 차이율, 종가의 캔들 범위 내 위치, 윗꼬리 비율 |
| 돌파 방식 | D0 시가가 이미 돌파선 위였는지, 갭 크기, 장중 관통 후 종가 유지 여부 |
| 저항·지지 | D-1 이전에 확정된 전고점과 전저점까지의 거리 |
| 독립 맥락 | 원천이 검증된 D-1 KOSPI/KOSDAQ 시장 방향 및 당시 종목 유동성 |

미래 가격이나 거래량으로 D0 특징을 만들지 않는다. 이동평균의 당일 포함 여부를 명시한다. 장중 실시간 분석이면 당일 확정 지표와 분리하고 D0 마감 후 연구라고 표시한다.

## 사후 결과 라벨 — 특징과 분리

- D+1 시가 기준, D+1/3/5/10/20 종가 잠정 수익 및 비용 10/20/50bps 민감도.
- 최대 유리/불리 가격(MFE/MAE), 돌파선 재이탈, 전저점 이탈, 돌파 유지 일수, 추후 리테스트 여부.
- D+1 이후의 정보는 D0 검색/등급/그룹 선정 조건으로 사용하지 않는다.
- 당일 봉 하나만으로 매집·주도세력·순매수를 판정하지 않는다.

## 검증·판정 문턱

- 기존 추세선 알고리즘의 선 정체성 먼저 고정. 수정 사항은 과거 실전 검색식을 조용히 바꾸지 않고 별도 연구 패치로 취급한다.
- 과거의 실제 당시 상장 종목 전부, 상폐/거래정지, PIT 데이터 출처, 누락 분모를 기록한다.
- 돌파 유형별 표본수·연도·종목 중복과 동시 신호 클러스터를 제시한다.
- 사전 선언한 특징의 단독·교호 분석 뒤 독립 2021~2025 시기·종목을 사용한 OOS를 수행한다.
- 평균·중앙값·하위꼬리·1건 제거 민감도·비용·시장 대조군까지 검토한 후 사용자에게 연구 결과만 보고한다.
- 결과가 유리해도 strategy_winner 없음, 실전 검색식·주문 변경 없음. 사용자 명시 승인 필수.
