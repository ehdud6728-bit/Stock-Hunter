# Stock-Hunter R5 — 삼성SDI 동일 추세선 확인 및 돌파 후 경로 예비 연구

연구일: 2026-11-19 · 상태: **RESEARCH_ONLY / 3종목 한정 예비 분석 / 전략 성능 검증 아님**

> 결론: 문제가 되었던 사건 날짜는 **2023-11-06**이다. 2026년 11월 사건이 아니다. R116 원래 코드와 보존된 삼성SDI 원본을 재생하면 **2023-11-02에 활성화된 중기 저항선과 2023-11-06 돌파 판정의 직전 활성선 ID가 동일**하다. 다만 사용자 HTS의 수정주가 계보가 과거 앵커일까지 동일하게 적용되었는지는 별도 가격원 확인이 필요하다.

## 1. 삼성SDI(006400) 추세선 신원

- 앵커 1: 2023-09-19, 음봉 몸통 상단 **566,000원(보존 원본 기준)**.
- 앵커 2: 2023-10-18, 음봉 몸통 상단 **522,000원(보존 원본 기준)**.
- 원래 선 ID: `TS_BODY_WICK_PROXY|BEAR_BODY_TOP|2023-09-19|2023-10-18|UPPER`.
- 원래 R116 중기(MEDIUM) 활성선: 2023-11-02 및 2023-11-03 모두 위 ID.
- 원래 R116 2023-11-06 `prior_line_id`: 위 ID 그대로, `prior_line_cross=CROSSED_ABOVE_PREVIOUS_ACTIVE_RESISTANCE`.
- 선 기울기: 거래일 바 1개당 **-2,750원**. 11-02 예상선 **491,750원**, 11-03 **489,000원**, 11-06 **486,250원** (보존 원본).
- 11-06 보존 원본 OHLC: **478,000 / 522,000 / 465,500 / 506,000원**.
- 사용자 캡처 화면 2023-11-06 OHLC: **467,962 / 511,038 / 455,725 / 495,374원**. 원본 OHLC의 **0.979배**와 원단위 반올림 오차 이내로 부합한다.
- HTS 캡처는 해당 날짜 **수정주가 환산과 일치한다는 관찰**만 증명한다. 이 0.979 계수가 **앵커 발생일인 9~10월까지 동일한 조정계수**였는지, 어떤 기업행위로 생겼는지, 독립 공급처와 일치하는지는 **미인증**이다. 가격 체계를 섞어 절대선 값을 직접 비교하면 안 된다.

증거: `results/SamsungSDI_2023_SAME_LINE_AUDIT.json`, `results/SamsungSDI_2023-11-06_RAW_vs_0979_adjusted.png`. 그래프 상단은 보존 원본, 하단은 **각 일봉 전체에 0.979를 곱한 동일계수 가정**을 표시한다. 하단은 실제 HTS 과거 앵커 수정주가로 독립 인증된 차트가 아니다.

## 2. R5 독립 돌파 경로 연구

기존 `r1d111/algorithms.py`, `r1d116/recent_turn.py`의 SHA-256을 잠그고 `TS_BODY_WICK_PROXY`의 **전일 활성 상단 저항선 종가 상향 돌파**만 추출했다. ENV10/20 하단 터치 연구와 사건을 합치거나 실전 로직을 수정하지 않았다.

- 종목: 삼성SDI(006400), 디오(039840), 롯데하이마트(071840). 2021~2024년 보존 KRX 일봉 3개 파일을 각각 SHA-256 고정.
- 선택 시점: **D0 종가 확정 후**. 이미 D-1에 알려진 동일 선으로 판정한다. 같은 종목·날짜에 기간이 다른 2개 이상 선이 돌파되면 **서로 다른 선 사건**으로 센다.
- D0 독립 설명변수: 직전 20일 평균 거래량·거래대금 대비 당일 배수, 직전 5/20일 거래량, 과거 20일 고저, 60일 파동 대리값, 당일 MA20/60/112/224 위치(원본 이력 부족하면 미상), 갭·종가 위치·윗꼬리·고정선 대비 거리.
- D+ 결과 라벨은 **사후 EXPOST로 분리**: D+1 시가 진입 가정부터 D+1/3/5/10/20 종가, 비용 총 10/20/50bp 가정, 기간 고저 기준 MFE/MAE, 같은 선의 재이탈/리테스트.
- 실제 거래 체결·슬리피지·거래세 상세·매수 가능 물량·상폐 종목 분모가 재현된 것이 아니다.

| 기간 선 | 선 단위 사건 | D+20 경로 완비 | D+20 평균·중앙값 (%; 총비용 20bp 가정) | D+20 동일선 재이탈(완비 사건 중) |
| --- | ---: | ---: | ---: | ---: |
| SHORT | 206 | 203 | -1.321 / -2.116 | 106 |
| MEDIUM | 186 | 185 | -1.312 / -1.794 | 100 |
| LONG | 114 | 112 | -2.344 / -1.432 | 69 |
| **합계** | **506** | **500** | 기간선 중복 때문에 단순 합산 평균 해석 금지 | 중복 가능 |

서로 다른 종목·신호일은 **368개**, 그날 돌파한 기간선 이벤트는 **506개**다. 특히 같은 종목·날짜의 SHORT/MEDIUM/LONG이 서로 종속되어 있으므로 개별 사건을 독립 시행으로 가정해 유의확률 등을 계산하면 안 된다.

삼성SDI 2023-11-06 중기 사건 예시: D0 거래량/직전 20일 평균 **2.737배**. D+1 시가에서 D+1 종가까지 총비용 20bp 가정 수익 **-6.059%**, D+20 기준 **-11.412%**. D+20 안에 **같은 고정선 아래로 재이탈**. 이는 **한 사건에 대한 사후 관측**, 그 당시 매수 신호 또는 일반화된 돌파 전략 결론이 아니다.

전기간·시장 전체·가격 조정계보·과거 상장종목 PIT 분모·지수 국면·OOS가 확보되지 않아 `strategy_winner=null`, `can_publish_strategy_performance=false`, `can_modify_live_search_watch=false`로 유지한다. 이 세 종목만으로 '추세선 돌파가 손해'라고도, 특정 필터가 유리하다고도 결론 내리지 않는다.

## 3. 재현 방법

저장소 루트에서 `numpy`, `pandas`, `matplotlib` 환경 필요.

```bash
python research_projects/trendline_breakout_quality_20261119/samsung_2023_same_line_audit.py \
  --out research_projects/trendline_breakout_quality_20261119/results
python research_projects/trendline_breakout_quality_20261119/r5_breakout_paths.py \
  --repo . --out research_projects/trendline_breakout_quality_20261119/results
python -m unittest discover \
  -s research_projects/trendline_breakout_quality_20261119 -p 'test_*.py' -v
```

출력:

- `SamsungSDI_2023_SAME_LINE_AUDIT.json`: 동일선 ID 및 사용자 화면 비율 확인.
- `SamsungSDI_2023-11-06_RAW_vs_0979_adjusted.png`: 보존 원본과 전체 날짜 0.979배 **가정** 비교 차트.
- `R5_BREAKOUT_PILOT_SUMMARY.json`: 주요 사건 건수·기간·종목·연도 및 연구 부적격 플래그.
- `R5_BREAKOUT_PILOT_AUDIT.json`: 사건·사전 특징·사후 기간별 라벨 원장.
- `R5_BREAKOUT_EVENTS_DPLUS_PATHS.csv`: 돌파 사건 × 기간별 사후 경로 전개.

입력/기준 코드 해시 불일치 시 **실패 종료**한다. 사용자 자료 또는 코드의 수정 후 재분석 시에는 해시 재승인이 선행되어야 한다.

## 4. 다음 연구 — 사전 정의 후 확장

1. **독립 주가 원천 이력**: 2023년 삼성SDI 보존 원본 vs 해당 HTS의 수정주가 이력·권리락/배당/액면 조정 계보를 앵커 2개까지 교차 확인한다. 보존 원본 결과와 수정주가 결과를 섞지 않는다.
2. **대표 모집단·PIT**: 당시 상장/상폐·거래정지 포함 전체시장 일봉, 지수 및 거래가능 시점, 누락률 분모를 확보. 동일 조건으로 재생한다.
3. **사전 정의 분류**: 돌파 형태(갭/장중 돌파 후 종가 안착), 거래량 증가 vs 선행 축적, 전고점·MA224 아래 1차 파동 후 눌림 등을 선택 시점 특징으로 기록하되 **성과를 본 뒤 역으로 문턱을 맞추지 않는다**.
4. **과거/미래 분리 OOS**: 연도·종목·신호 중복을 통제하고 D+ 경로와 비용을 동일하게 비교. 소규모 3종목 결과는 설명·디버깅 용도로만 보존한다.

기존 LIVE/SEARCH/WATCH, 기존 매매 조건검색식과 Actions 운영 스케줄을 변경하지 않는다.
