# Stock-Hunter R1-D109 — 변곡점 확정·동적 추세 변화·전체 기술 지표 동시 연구 (RESEARCH_ONLY)

## 연구 목적

추세선 품질점수나 단순 돌파 횟수가 아닌 **추세의 변화가 어떻게 시작되고 확인되는가**를 분석합니다. 과거 추세선은 절대 지우지 않으며, 활성선 이탈·재기준점 설정·새 선 대기·과거 선 재접촉을 분리합니다. 실제 종목은 디오(039840), 롯데하이마트(071840), 삼성SDI(006400)입니다.

## 원본 불변 / 실행 경로

기존 단일 파일 `.github/workflows/stockhunter_r1d98_state_structure_research_only.yml`에 `study: r1d109` 선택지만 추가합니다. 새 GitHub Actions YML 파일을 만들지 않습니다. `r1d109` 선택 시 **R1-D105 → R1-D106 → R1-D108 → R1-D109** 순서로 실행합니다. R1-D107 단독 전체 연구 실행은 필요하지 않습니다. R1-D96~D108, LIVE/SEARCH/WATCH는 동결 보존합니다.

입력은 R1-D108의 전체 PIT 날짜×320열 테이블, 활성 추세선 상태·별도 사후 종가 테이블, R1-D106의 불변 추세선 이력입니다. 파일 해시를 분석 전후 비교합니다. 동결 KRX CSV를 직접 재계산하는 R1-D105/R108 단계와 연결되므로 본 분석은 이미 생성된 두 연구 산출물을 사용합니다.

## 구성

1. **피벗 확정 이벤트**: 국소 고점/저점은 좌우 두 거래일을 확인합니다. 2일 전 피벗은 오늘 장 마감 때야 확정되며, 출현일로 신호를 소급하지 않습니다. 확정된 연속 고점과 저점의 더 높음/낮음/비슷함(±0.3% 연구용 허용폭) 및 구조(HH/HL, LH/LL, 수렴/확산)를 PIT 기록합니다.
2. **기존 활성선→신규 활성선 변화**: R1-D108 네 개 영역(단기/중기 상단·하단)의 신규 갱신 순간에만 이전 기울기와 신규 기울기를 비교합니다. 상승↔하락 기울기 부호 전환, 더 완만함/가팔라짐, 같은 가족 추세선 여부를 구분합니다. **기울기 부호가 바뀌었다는 것이 가격 추세의 확정 반전은 아닙니다.** 특히 다른 캔들 계열의 선으로 바뀐 경우는 구별합니다.
3. **지지선 이탈과 저항선 돌파 후 역할 바뀜 추적**: 기존 선은 불변 이력으로 남깁니다. 돌파 후 최대 10거래일 동안 당일에 확인 가능한 구선 가격의 재접촉, 지지/저항 역할 후보, 재이탈/재회복을 관찰합니다. 돌파 당일에 미래의 재접촉을 알고 있었다고 가정하지 않습니다.
4. **전 기술지표 동시 추적**: 기존 R108의 13개 이평선(3,5,10,20,30,40,60,112,120,224,240,448,480) 기울기·이격·가속도, BB20/30/40 폭 및 상하단 기울기, ENV20/40, 일목/MA 구름 두께·높이·방향, 캔들 몸통·꼬리·종가 위치·직전 2~3일 봉과 비교, 거래량·거래대금을 날마다 그대로 유지합니다. **수익률을 사용한 가중합 점수는 없습니다.**
5. **전환 이전 과정**: 구조 사건일 D-5/D-3/D-1/D0의 실제 당시 기술 지표를 저장하고, D+1/3/5/10/20 사후 결과는 별도 `EXPOST` 파일로만 보관합니다. 동일 종목 겹침 날짜는 독립 표본이나 승률로 세지 않습니다.

## 해석 제한

세 종목의 과거 표본은 대표성이 없습니다. R108 분석 가능일의 시작 idx541 전에 형성된 피벗은 R109 별도 피벗 비교에서 제외됩니다. 구조 반전, 지지/저항 재테스트도 원인이나 성공 확률이 아닙니다. 후보선은 4영역에서 중복될 수 있습니다. 과거 주가를 액면분할 등 기업행동에 전부 보정했다고 주장하지 않습니다. 단계별 비교 결과가 나와도 아직 LIVE/SEARCH 조정은 하지 않습니다.
