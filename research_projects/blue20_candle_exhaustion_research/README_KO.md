# Stock-Hunter BLUE20 돌파일 장대양봉 × ATR × 이격 × 거래대금 × 하루 확인 연구

- 버전: `BLUE20_UPPER_CANDLE_EXHAUSTION_R1_RESEARCH_ONLY`
- 연구 모집단: 기존 R118 고정 2022년말 500종목 / 2023–2024년 사건 / BLUE20 명확한 몸통 돌파 + RSI Wilder14/SMA9 D0~D+10 골든크로스 / 다음 날 시가 / D0+20 청산.
- 모집단 1,804건(상단 834, 하단 970) 전체에서 돌파일 지표를 전수 계산하되, **하루 확인 뒤 진입 전략은 상단 돌파 & RSI D0만** 별도 동일 모집단 비교. 다른 RSI 지연 사건과 성과를 섞지 않음.
- 2023~2024년 연구 표본에서 발견된 상관관계는 미래 데이터 성과 또는 원인 증명이 아님. LIVE / SEARCH / WATCH 및 R1D118 기존 코드 변경 금지.

## 연구 가설

1. 긴 양봉이 모두 나쁜 게 아니라 **전일 대비 상승률, 양봉 몸통/ATR20, 종가 위치 및 윗꼬리, 60일선 이격, 60/112일선 기울기, 거래대금 급증**의 조합이 다음날 손절 위험을 좌우할 수 있음.
2. 거래대금 급증 ≠ 외국인·기관 매수 확정; 체결강도 자료 부재. OHLCV 단순 활동량 대리지표.
3. **D0 장대양봉은 그날 종가 이후 알려진 사실이므로 D1 시가부터 이용 가능.** D1 캔들·거래대금 확정 정보는 D1 장 종료 후에야 알 수 있으므로, 반드시 D2 시가 이후 진입에만 사용.
4. 장대양봉 제외만이 아닌, 다음날 캔들 지지를 확인하여 한 거래일 늦게 진입하는 전략을 원래 D0+20 고정 관측창으로 비교. 추격 매수를 놓쳐 발생한 기회비용을 포함.

## 연구 지표

- D0 전일종가 대비 +5 / +10 / +15 / +20% 구간. 당일 시가→종가 몸통 등락률 별도 저장.
- `|D0 종가-시가| / 직전일 ATR20`: 1 / 2 / 3배 구간. 분모는 **D0 직전일까지** 확정된 True Range 20일 단순평균으로, D0의 급등이 분모까지 키우는 왜곡을 방지합니다. 참고용 D0 포함 ATR20도 원장에 같이 출력합니다.
- `D0 종가 / MA60`: 음수, 0~5, 5~10, 10~15, 15~20, 20%+ 구간. MA112·MA224 원시 수치와 MA 기울기 보존.
- D0 당일 거래대금 / D0 직전 **20거래일** 평균: <2 / 2~5 / 5~10 / 10~20 / 20+배.
- D0 캔들 윗꼬리 비율, 종가의 전체 가격범위 내 위치. 5/20일 직전 수익률(돌파일 제외).
- D0 한정 위험 후보기준: 거래대금 10배 이상 + MA60 10일 기울기 하락 + MA112 10일 기울기 하락; **검정 이전 선언한 탐색 조건이지 자동 제외 규칙 아님.**

## 거래 가정 — 진입 시점 오류 엄금

- 원본: `RSI GC 확인 다음 거래일 시가(D0 GC는 D1 시가)`에 매수. 장중 고가 +10% 익절 / 저가 -5% 손절. 한 봉에 양쪽 도달 시 손절 우선. 갭 이탈 체결은 시가로 처리. 왕복비용 0.25%p. D0+20일 종가 시간종료.
- 연구 4개 대기 정책은 모두 **D0 RSI 골든크로스가 동시 발생한 상단 돌파**에서만 평가.
  - `D1_CLOSE_HOLD_BODY_MID`: D1 종가가 D0 양봉 몸통 중간값 이상
  - `D1_CLOSE_HOLD_UPPER_BAND`: D1 종가가 그날 표시되는 SHIFT(BBandsUp(20,2),26) 이상
  - `D1_BOTH_MID_AND_UPPER`: 두 조건 모두
  - `D1_CLOSE_ABOVE_D0_HIGH`: D1 종가가 D0 고가 이상
- 각 정책은 D1 **종가에만 평가**, 만족할 때 D2 **시가**에 가상 매수. 미충족 시 거래 없음, 해당 사건 수익률 0%. **실행한 거래만의 평균**과 **모든 기회수 대비 평균**을 반드시 함께 보고하며, 원본과의 비교 모수는 동일 D0 모집단.
- 갭 급락 체결 위험 때문에 -5%가 최대 보장 손실이 아님.
