# R16 — 과거 5종목 밖에서 R116·R14·R15 그대로 다시 보기

## 작업 목적

**같은 5종목에서 매도선을 바꿔가며 평균 수익이 양수가 될 때까지 시험하지 않습니다.** 종목 선택 결과나 미래 수익을 보지 않은 상태에서 새로운 종목 30개를 먼저 고정하고, 이미 합의한 R116 돌파 신호/R14 구조 기반 청산/R15 최고수익 확보 진단을 **그대로** 적용합니다.

## 데이터 표본의 진짜 의미

- 기존 저장소의 SHA 고정된 `R1D27D_ALLMARKET_85576_TICKER_DATES_SOURCE_QUEUE.csv.gz`에는 2021~2025년 과거 BB 신호를 발생시킨 **2,225개 종목코드**가 있습니다. 전 종목 무작위 추출 명부는 아닙니다.
- 이 명부에서 **종목코드만 사용**하고, `R16_UNSEEN_CODES_V1_20261121|코드`의 SHA256 해시가 작은 순서로 30개 고정. 기존 개발 종목 `006400, 039840, 071840, 053800, 220260`은 명시적으로 제외. 과거 신호 날짜/성과는 선택에 쓰지 않습니다.
- 30개 종목 선택은 코드·정렬 기준·상위 숫자를 소스에 사전 고정하고, 원본 명부의 SHA256이 변하면 즉시 거부합니다. 누락/수집 실패한 종목을 결과가 좋아 보이는 다른 종목으로 대체하지 않습니다.
- **이것은 독립된 종목코드로 하는 예비검증이지 전체시장 대표성을 갖춘 확정적 OOS가 아닙니다.** 개발 종목과 기간이 겹치고, 명부 자체가 과거 신호 발생 종목의 편의 표본입니다.

## 실제 데이터가 아직 필요한 이유

- 리포지토리에는 새 30개 종목의 **2020~2025년 전체 일봉 OHLCV**가 들어 있지 않습니다. 따라서 GitHub PR 검증은 종목 고정/소스 검증/가짜 가격 테스트까지만 실행합니다. **PR에서 초록색이 나왔다고 백테스트가 성공한 것이 아닙니다.**
- 전체 데이터 수집은 GitHub Actions `workflow_dispatch`에서 사용자가 `confirm_public_krx_collection`을 직접 켜야만 실행합니다. 공개 KRX 데이터 조회에 필요한 것은 2026년 pykrx `1.2.9`의 **KRX_ID/KRX_PW**이며, KIS API 키/시크릿과 **다른 자격증명**입니다. 이 둘이 Repository Secrets에 없다면 실행을 중지합니다. 로그인 차단 시 우회하지 않습니다.
- 새로운 KRX 계정을 만드는 것이 부담스러우면, 이미 키가 설정된 **BLUE-Signal-Lab KIS 시세 수집 경로**에서 같은 30개 코드의 OHLCV를 내보내는 별도 연구 전용 흐름으로 바꿔야 합니다. 그 데이터가 실제로 2020~2025년의 일봉 가격을 완전하게 제공하는지부터 확인해야 합니다.
- 기존 5종목 데이터를 KRX에서 재수집해서 새로운 표본인 것처럼 사용하지 않습니다.

## 데이터 품질 규칙

- 고정 30종목, 고정 기간 `2020-01-01~2025-12-31`, `adjusted=False`, 소스당 최소 280개 유효 거래일; 원본 일봉 정합성·중복·0원/결측 가격·기업행위 의심 급격한 갭 여부를 검증합니다.
- 거래정지일의 0원 또는 공급자 이상치를 수익 0으로 만들거나 앞뒤 날짜로 보정하지 않습니다. 문제 있는 종목은 `UNKNOWN/REJECT`로 남기고 대체하지 않습니다.
- 원본 `.csv.gz` 바이트 SHA256·종목별 조회 성공/실패/첫일/마지막일을 Manifest로 봉인한 다음에만 신호와 미래 가격을 계산합니다.
- **유효 가격 종목 10개 미만이면 평가 중단**, D+20과 D+60이 모두 완료된 구조 진입 이벤트가 **20건 미만이면 검증 결과로 인정하지 않습니다.** 이 두 개수는 수익 최적화값이 아니라 데이터 부족 중단 규칙입니다.
- R116 원본 2020년 앵커 진입 이후 발생한 2021~2025 돌파를 계산하며, **종목별 60일 비중복**을 유지합니다. 고정된 R14 두 청산 규칙, R15 사후 실현 수익/놓친 상승/피한 하락을 사용하고 새 손절·익절 % 기준은 넣지 않습니다.

## 사용법

1. [R16 Actions 워크플로](../../.github/workflows/stockhunter_r16_new_ticker_source_pilot_research_only.yml)의 PR 자동 테스트로 원본·종목 선택이 변하지 않았는지 확인.
2. 가격 수집에 필요한 KRX 계정이 이미 Repository Secrets `KRX_ID`, `KRX_PW`로 설정되어 있을 때만 `Actions > Stock-Hunter R16 > Run workflow`에서 **명시적으로 수집을 허용**.
3. 성공 시 `STOCK_HUNTER_R16_TICKER_DISJOINT_SOURCE_RESEARCH_ONLY` 아티팩트에서 `R16_SOURCE_MANIFEST.json`, `R16_FROZEN_HOLDOUT_UNADJUSTED_OHLCV.csv.gz`, `R16_HOLDOUT_SUMMARY.json`, `R16_HOLDOUT_FULL_AUDIT.json` 확인.

별도 GitHub Actions/연구 폴더 외의 기존 **LIVE·SEARCH·WATCH·매매 주문·KIS 키·실제 조건검색식에는 변경 사항이 없습니다**. 이 파일의 값은 실전 매매를 권고하지 않습니다.
