# Stock-Hunter 종가매매 — 원본 시세·검색 조건 검증 1차 감사

2026-11-17 · `RESEARCH_ONLY` · 기존 LIVE/SEARCH/WATCH/주문/성과 산출 코드는 수정하지 않음.

## 결론

추가 조건을 만들기 전, 실제 시세와 검색 조건이 일치하는지 입증해야 한다. **현재 저장소의 코드만으로 특정 종목의 실제 종가매매 성과나 검증 완료를 선언할 수 없다.** 이번 감사는 발견한 위험을 코드 근거와 독립 재현 테스트로 고정하며, 실제 원천 데이터가 준비되면 동일한 테스트를 돌리는 연구 도구를 분리해 둔다.

## 소스에서 확인한 사실

1. `Closing_bet_scanner_v2.py`의 `_base_info`는 `Amount`가 없으면 `Close * Volume`을 사용한다(약 2713~2729행). `_v4958` 진입맥락 계산 역시 `Amount` 누락 시 같은 대체값을 사용한다(약 681~725행). 또 하단 밴드 선택 관련 함수에서는 `Close * Volume`으로 20일 평균 거래대금을 직접 계산한다(약 3615, 3681행). **거래량 × 종가는 실제 체결대금과 동일하지 않다.** 500억원 근방에서는 합격/불합격이 바뀔 수 있다. 기존 코드가 모든 조건에서 500억원을 필수로 강제한다고 주장하는 것은 아니다.
2. `v49_76_input.py`의 `history_authority_row`는 금액 출처(`Amount` 또는 `Close*Volume`)와 원천 데이터 해시를 별도로 기록한다(약 74~119행). 좋은 감사 기초는 이미 있다. 다만 출처 기록/재현 가능하다는 사실은 **공식 시세와 일치한다는 독립 검증**과 다르다.
3. `search_spec_v7.json`에는 12개 모드(L, LP, SLOCK, S, G, IT, H, I, A, B1, B2, C)별 의도 조건·구현 함수·원천 해시가 기록되어 있다. `v49_76_quality.py`의 `INTENT_PROXY_SPECS`는 **독립 의도 확인용 대리 지표**이며 원본 검색 조건을 대체할 수 없다고 명시한다. 따라서 대리 지표 통과만으로 검색식의 충실성을 증명하면 안 된다.
4. `v49_76_merge.py`의 `_performance_table`은 수익률 `rule35_pnl`에서 0.20/0.50%포인트를 **고정 차감**한다(약 145~151행). 실제 거래별 호가·체결·수수료·세금 대장에 기반한 순수익이 아니다.
5. `v49_76_research.py`의 `_equity_metrics`는 각 신호일 최고 점수 종목 한 건을 택한 후 거래 수익률을 신호일 순서대로 누적한다(약 102~123행). 보유기간 겹침·현금·진입/청산 시점의 거래 가능한 계좌 곡선을 구축하지 않으므로 출력 `portfolio_mdd_pct`를 **실계좌 최대낙폭**으로 해석할 수 없다. 같은 파일의 테스트 기간 라벨은 기존 연구에서 이미 노출된 기간임을 스스로 명시한다(약 79행).
6. `v49_76_prepare.py`는 종료 시점 KRX 거래일을 기준으로 전체 샤드에 쓸 종목 집합을 준비한다(약 30~44행). `v49_76_pit_marcap.py`는 역사적 신호일 시가총액과 종료 시점 시가총액 차이를 후속 감사하지만, 결과에 `full_reverse_replay_performed: False` 및 역사적으로 가능했으나 종료시점 필터에서 누락된 종목을 복원하지 못한다는 경고를 남긴다(약 321~329행).
7. `closebet_research/r124_frozen_hypotheses.json`은 과거 907개 종목 데이터가 **시점별 전체시장 원본이 아닌 사후 선택 집합**이며, 미래 OOS 검증이 완료되지 않았다고 명시한다. `closebet_research/r125_prospective_capture.py`는 이를 보완하기 위한 당일 시점 전체시장 데이터 확보 경로이지만 현재 이 로컬 감사에서 실제 수집 성공 결과를 검증한 것은 아니다.

## 다음 연구는 세 층의 별도 합격 검사가 필요

### 1단계: 원천 시세 동일성 (먼저)

- 종목코드/거래일/시장/수정주가 여부/분할·합병 보정/거래정지 날짜를 일치시킨다.
- D0 시고저종·거래량·**공식 체결 거래대금**을 KRX 등 독립 원본과 대조한다. 원천 API, 수집 KST 시각, 원본 해시, 수정/비수정 가격 정의를 저장한다.
- 중복 바, 누락된 장, 0/음수 거래량, `low > open/close` 등 오류는 성과표에서 제외하고 `INVALID`로 격리한다.
- 거래대금 공식 원본이 없다면 `Close*Volume`은 **추정치**로 기록하며, 500억원 조건 합격으로 확정하지 않는다.
- 112일선/224일선은 **D0까지의 112/224개 공식 거래일 종가**로 산출한다. 부족한 과거일 수는 `UNKNOWN`으로 처리한다.

### 2단계: 검색식과 차트 의도 동일성

- `search_spec_v7.json`의 모드별 **구현 함수와 실제 참/거짓 판정**을 고정한 상태에서 검증한다.
- 신호 발생 예뿐 아니라 **발생하지 않은 날짜·종목**에서도 독립 기준으로 기대 신호를 확인한다. 성공 차트만 보는 선택편향 금지.
- 각 조건을 `PASS/FAIL/UNKNOWN`과 **실제 수치, 당시 기준값, 적용일**로 기록한다. 데이터 누락은 FAIL이나 PASS로 바꾸지 않는다.
- 양성 10건·음성 10건부터 차트와 독립 확인. 초기에 예쁜 승자 차트보다 **명백한 오류 사례**를 우선한다. 3회 연속 수정 없이 일치한 뒤 모드별 샘플 확장.
- 자동화된 검색식 일치율은 실전 조건의 충실성과 데이터 완전성 확인 후에만 발표한다.

### 3단계: 거래 가능한 성과

- 1, 2단계 모두 통과한 사건만 분석한다. D0 15:00 시점에 실제 확보 가능한 정보, 15:20 종가동시호가 구간, 종가/다음날 시가 진입을 구분한다.
- 3/5/10/20일 수익률뿐 아니라 일봉에서 수익/손절이 동시에 터치한 사건은 `순서 미확인` 또는 보수/낙관 범위로 분리한다.
- 체결가능 수량·비용·동시보유 상한·현금잔고·상폐/거래정지·미완료 관찰 구간을 포함해 일별 계좌 곡선을 재산출한다.
- 500억원, 112/224일선, 기존 강의 PDF의 종가매매·기준거래대금은 **사전 등록한 가설**로 별도 비교하고, 실적을 보고 문턱을 이동하지 않는다.
- 데이터와 검색식이 확정된 이후에만 시간순 학습→검증→진짜 미래 자료의 OOS 수행. 기존 RESEARCH_ONLY 외에는 코드 자동 적용 금지.

## 새로 추가한 독립 검사 도구

`audit_casebook.py`는 이미 발행된 신호 CSV와 독립 일봉 CSV를 입력받아, 0일 종가·거래대금(억원)·캔들 종가 위치·윗꼬리·전일 대비 갭·거래량 20/50평균 비율·거래대금 20평균 비율·MA20/60 이격 등을 **독립 재계산**한다. MA112/224와 거래대금 500억원 통과 여부도 표시한다. `casebook.csv`, `summary.json`을 별도 결과 폴더에 생성한다.

```bash
python research_projects/closebet_source_parity_20261117/audit_casebook.py \
  --daily /path/to/independent_daily.csv \
  --signals /path/to/frozen_signal_ledger.csv \
  --out /path/to/new_research_result
```

`--daily` 최소 열: `code,date,open,high,low,close,volume,amount` (권고 `amount_source`).
`--signals` 최소 열: `code,signal_date,mode` (진입맥락 열들이 많을수록 검사가 유의미하다).

**사용 제한:** 입력 가격은 원본 데이터임을 별도로 검증해야 한다. 이 도구는 **양성 신호의 진입맥락 일치 검사**이지, 전체 검색 조건의 완전한 독립 재현이나 음성/누락 신호 판별이 아니다. 소스 출처 라벨만으로 공식 데이터 정합성 `PASS` 판정을 내리지 않는다. 실제 역사 자료를 이 도구로 분석했다는 주장도 하지 않는다.

## 현시점 중단·계속 결정

**종가매매 연구는 계속하되, 수익률 최적화는 일시 중지.** 먼저 데이터/조건 검증 실패율과 원인별 사례를 만들어 고친다. 확인되지 않은 데이터·조건은 성과 계산에서 자동 배제해야 한다. R124 같은 기존 독립 연구와 v49.76은 모집단과 진입시점이 다르므로 결과를 한 승률 표에 합치지 않는다.
