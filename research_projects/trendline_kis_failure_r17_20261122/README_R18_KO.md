# Stock-Hunter R17/R18: 큰 손실 예측 우선 연구 (RESEARCH_ONLY)

## 실험에서 답하려는 질문

단순히 한 번 1ATR 상승 또는 하락이 먼저 발생할지를 예측하는 것이 아니라,
**기존 구조적 손절에서도 큰 손실이 난 거래를 신호 당시에 구분할 수 있는가?**

수익률이 높은 사례 몇 개만 보고 손절선을 넓히는 방식을 쓰지 않는다.
미래 최고가(MFE)는 사후 진단에만 활용하며 실시간 익절 목표가가 아니다.

## 데이터 및 재현성

- 원천: `BLUE-Signal-Lab` Actions run `44988188271`의 KIS 원시 일봉 30종목, 총 42,782행.
- 수집 CSV SHA-256: `e5edabf1b111d424a0afa8503111d7dd4d6e4827036aa7eea512ef067d122dbc`.
- R16 기존 구조적 검증과 동일하게 35% 이상 극단적 미조정 갭 등 4종목 제외, 26종목 통과.
- 기존 R116/R14/R15 본체는 변경하지 않음. 동일 신호, 60봉 내 중복 방지, D+20·D+60 경로 모두 확인된 425건만 사용.
- 2021~2023년 275건 학습, 2024~2025년 150건 검토. 소스 데이터 무결성과 제외 코드 명단을 재검증.
- KIS 토큰/시크릿, D1, LIVE/SEARCH/WATCH를 전혀 요청하거나 변경하지 않음.
- `R17`은 고정 퍼센트 없는 D0 저가/직전 5일·10일 저가 이탈 청산을 기존 구조 손절과 비교한다.
- `R18`은 거래 당일 종가까지 확정된 6개 특성을 이용. D+1 시가는 **별도 보조 비교**에서만 사용한다.

## 사전 고정한 위험 분류

- 큰 손실 기준은 학습기간 기존 장중 구조 손절 수익률 분포의 **하위 10%**.
- 이 10%는 **라벨 분포 기준이지 손절 -10% 또는 -5%를 설정한 것이 아님**.
- 모델: 6개 입력의 중앙값 결측 보정 → 표준화 → 정규화된 로지스틱 회귀 (`C=0.25`). 임계값이나 모델을 검증기간 수익률로 최적화하지 않음.
- 위험군 구분: 학습 점수 분포의 상위 25%. 검토기간 점수로 임계값 재조정하지 않음.
- 스트레스 평가: 종목코드 SHA로 고정한 5개 폴드. 각 폴드에서는 해당 검토 종목을 학습 데이터에서 **전 기간 제외**.
- R14 손절의 수익률을 라벨로 삼으므로, 이 위험 경보는 **다른 매도 전략의 손실 위험 예측으로 외삽할 수 없음**.

## 현재 발견 (설명용 파일에서 재현 가능)

- 동일 425건 중 검토기간 150건, 학습 하위 10% 손실 기준으로 큰 손실 12건.
- 사전 고정 모델+종목 비중복/시간 분리 검토 AUC 약 **0.898**.
- 위험군 30건 중 큰 손실 9건; 나머지 120건 중 큰 손실 3건.
- 가상 필터 적용 시 기존 R14의 검토기간 평균 -0.76% → -0.30%, **여전히 음수**.
- 2024~25 성과를 앞선 R16/R17 분석에서도 보았으므로 이번 검토는 pristine OOS가 아님.
- 검토기간의 심각한 손실이 12건뿐이고, 26종목은 전체 시장 무작위 표본이 아님.
- 성공적인 손익비를 입증했다거나 LIVE에 추천필터를 넣을 근거가 아님.

## GitHub Actions 실행

1. PR의 자동 테스트가 통과한 뒤 병합한다.
2. `Actions → Stock-Hunter R18 KIS Big-Loss Warning Research Only → Run workflow`.
3. `confirm_research_only_kis_replay=true` 선택.
4. 같은 원천 아티팩트를 다운로드한 뒤 R16 재현→R17 구조청산 비교→R18 큰 손실 경보를 차례로 실행.
5. 업로드 결과물은 `R18_SUMMARY.json`, `R18_UNSEEN_TICKER_TEMPORAL_SCORES.json` 등 진단 정보만 포함하며 원본 KIS 일봉을 중복 업로드하지 않는다.

주의: 원천 GitHub Actions 아티팩트는 만료될 수 있다(최초 만료 예정 2026-12-06 UTC). 원천이 없거나 접근 권한이 없으면 **실패가 정상**이고, 새 데이터를 묵시적으로 섞거나 다른 종목으로 대체하지 않는다. 이후 신규 수집분을 연구하려면 별도 핀·감사 절차를 거친다.

## 실전 적용 전 필요한 일

1. 종목과 날짜를 새로 고정한 다른 데이터에서 블라인드 재검증.
2. 종가 단일가 / 시간외 종가 별로 신호 확정 시점 및 실제 체결 가능성 감사.
3. KIS 미조정 주가의 기업행동 독립 검증, 상장폐지·생존편향 및 장세 통제.
4. '위험군을 걸러낸 뒤' 실제 손익비와 하위 손실폭을 동적으로 연구하되, 고정된 LIVE·SEARCH·WATCH와 분리.
