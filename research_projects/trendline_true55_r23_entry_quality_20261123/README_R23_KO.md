# Stock-Hunter R23 — 55일 돌파 진입 품질과 기존 224일선 아래 거래량 축적·1차 파동·눌림목 의도 복원 감사

**RESEARCH_ONLY**. R19/R20/R21/R22의 원본, 운영용 LIVE·SEARCH·WATCH, 검색 조건식과 주문 정책은 수정하지 않습니다.

## 왜 R23인가?

R20~R22의 매도 방식 비교에서 전체 149건의 중앙 순수익률은 대체로 음수였습니다. 이는 매도 문제뿐 아니라 애초에 **55일 돌파 신호 중 진입 질이 낮은 사건이 섞여 있을 가능성**을 시사하지만, 현재 데이터만으로 원인을 확정할 수 없습니다.

사용자가 원래 원한 형태는 *224일선 아래에서 거래량이 서서히 유입 → 1차 파동 → 눌림목 → 재상승 시점 포착*입니다. 55일 최고가 돌파가 이것과 동일한 패턴이라고 주장하지 않고, 먼저 차트의 사전 구조가 얼마나 겹치는지 연구합니다.

- R19의 60일 종목별 중복 제거, D+60 경로, D+1 시가 가격 조건을 거친 **고정 149건**의 종목·날짜만 R22 사건 원장과 대조하고 동일 실현 매도손익을 분석합니다.

## 특징은 모두 D0 확정 종가 이전 정보만 사용

| D0에서 측정하는 요소 | 원래 의도의 탐색 대리변수 |
| --- | --- |
| 224일선 | D0 종가가 D0 포함 SMA224보다 낮으면 YES |
| 거래량 및 거래대금 누적 | D-20~D-1의 평균이 D-80~D-21의 평균보다 각각 **1.25배 이상**이면 YES |
| 1차 파동 | D-60~D-31을 바닥 구간, D-30~D-11을 파동 구간으로 고정. 파동 고가가 앞 구간 최고가를 넘고 앞 바닥 저가 대비 최소 **12%** 상승 |
| 눌림목 | D-10~D-1의 저가가 앞 바닥 저가보다 높고, 파동 고가에서 **3~25%** 눌린 경우 |
| 눌림 중 거래량 감소 | D-10~D-1 평균 거래량이 D-30~D-11 평균의 **0.8배 이하** |
| D0 거래대금 유입 | D0 거래대금이 D-20~D-1 평균의 **1.5배 이상** |
| 복합 원형 | 224 아래 + 거래량·거래대금 누적 + 순서가 고정된 1차 파동·눌림목 동시 충족 |

이 수치들은 *연구자가 선정한 사전 정의 대리변수*로서 실제 원형 패턴을 완전히 재현한다는 뜻이 아닙니다. 특히 단순 20일 평균으로 실제 누적 매수세, 체결 방향, 가격대별 매물대를 파악할 수는 없습니다. 임계값이 좋게 나오면 그것을 뒤늦게 정답으로 채택하지 않습니다.

어떤 조건은 과거 데이터가 부족하거나 거래량·거래대금 기준이 0이면 **UNKNOWN**으로 보존합니다. UNKNOWN을 NO나 0% 수익률로 바꿔서는 안 됩니다. D+1 이후 가격과 사후 최고가(+30% MFE 여부)는 **평가 레이블**일 뿐 특징에 사용하지 않습니다.
