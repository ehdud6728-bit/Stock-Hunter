# R1-D114: 다중 활성 추세선 보존 + 구조 경계 재분류 + 모든 구조 사건일 전체 지표 (RESEARCH ONLY)

## 연구 목적
- **A축 기존 추세선**: R1-D112를 변경하지 않음. 4개 자동 방식 × 단/중/장기 × 상/하단 = 24 활성선 상태를 읽기 전용으로 유지.
- **B축 구조 패턴**: R1-D113의 모든 후보를 보존하면서 `수평 박스, 상승/하락 채널, 삼각수렴, 상승/하락 쐐기`의 **전체 관찰 기간 기울기와 폭 변화**로 재분류.
- **C축 통합 연구**: 모든 R1-D113 구조 사건 날짜에 동결 R1-D97 원시 OHLCV로부터 이평선 13개·BB20/30/40·ENV20/40·이평선 구름대·실제 표시 가능한 일목 구름대·캔들·거래량/거래대금을 다시 계산. 기존 R1-D109의 일부 날짜에만 있는 30.3% 스냅샷에 의존하지 않음.

## 엄격 구조 판정 원리
`upper_m/lower_m`는 R113가 **해당 asof 종가까지 확정한 피벗**을 통해 계산한 과거 경계선이다. 경계선 생성 알고리즘은 R113 그대로이며 **미래 가격이나 인간 지정 기준일을 사용하지 않는다**.
- 박스: 전체 관찰기간 상하단 각각 가격 이동 ≤ 2% 및 구조 높이의 30%, 높이 변화 ≤ 30%.
- 채널: 양쪽 경계선이 같은 방향으로 각각 ≥ 2% 이동하며 경계 평행성·채널 폭 안정성 확인.
- 수렴: 시작 대비 폭 감소 ≥ 20%, 수렴 꼭짓점은 현재보다 ≥ 2봉 이후, 분류별 기울기 부호 확인.
- 기본 R113의 2회 이상 접촉과 몸통 포함률 ≥ 62%를 보존.
- 고정 수치는 연구용으로 선택했으며 수익률에 최적화되지 않았다. **새 구조 명칭이 눈으로 보는 것과 완전히 같다는 보장은 없으며, 파라미터 민감도 검증이 남아 있다.**

## 추세선/구조 생명주기
- 이전 구조가 오늘 다시 탐지되지 않았다는 이유만으로 즉시 종료하지 않음; 마지막 확정 경계를 최대 5거래일간 유지.
- **전날까지 확인된 구조의** 상단 돌파/하단 이탈이 알려진 날 종료 기록. 새 구조는 종료일부터 다시 만들 수 있으나 돌파 전 이미 존재했다고 표시하지 않음.
- 새 기준점에 따른 경계 변화 > 현재 구조 높이의 35%이면 `ENDED_MAJOR_REANCHOR` → 새로운 구조 생성. 동일 구조면 `UPDATED_SAME_STRUCTURE`.
- 모든 `regime_id`와 `formed_asof`를 기록한다. **이 구조 관찰 구간은 사람이 눈으로 정의한 실제 상승/하락 사이클과 동의어가 아니다.**

## 원본 보존 및 사후오염 방지
- R1-D112/R1-D113 소스·CSV를 절대 덮어쓰지 않는다. SHA-256 재검증.
- R113의 구조 돌파/이탈 기록 668건과 보관 기록 총 793행은 **한 행도 삭제하지 않고** 새로운 적합/부적합 표식을 추가한다.

- **일목 가시 구름대**는 26봉 전 산출된 선을 오늘 관측하므로 미래 참조 없음. 과거 연구의 일목 변수와 다르게 계산된 경우를 명시하며 일괄 동일성은 주장하지 않음.
- D+1/3/5/10/20 사후 결과는 R113의 기존 EXPOST에 있으며 R114의 선별 기준으로 사용하지 않는다.
