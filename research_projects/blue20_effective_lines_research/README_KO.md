# BLUE20 종목별 유효선과 눌림 독립 연구

기존 고정 500종목의 2023~2024년은 개발 구간이고 2025~2026년은 선택을 고정한 시간순 검증 구간이다. 원래 기준선의 500개 가격 해시, P1 날짜와 완전한 P2·P3 경로를 확인한다. 종목 모집단은 상장 시점 기준으로 확대하지 않았다. 후반 가격은 [기존에 고정한 FinanceData 마켓캡 커밋](https://github.com/FinanceData/marcap/tree/50f4d1a74e87c720a03e576218036b1b8414afa1/data)의 해시 검증 원시 가격이다. 상장·거래 중단 및 기업행사 총수익은 미확인이다. 실제 투자자별 순매수는 사용하지 않았다.

## 기준

- BB20·25·30·35·40 모두 기존 종가 SMA와 모표준편차, 배수 2·26거래일 이동과 1.8·20거래일 이동을 유지했다. 엔벨로프 중심선은 이동 없는 SMA20이다. 기존 BB 상·하단 및 엔벨로프 중심 몸통 돌파식을 그대로 사용하며, BB 중앙선 몸통 돌파는 이번 보조 관측이다. 첫 장대양봉 P1 및 P2/P3 규칙은 초기 파동 연구와 같다.
- BB40 1.8·20의 상대 밴드폭이 직전 20일 중앙값의 80% 이하로 처음 들어간 날을 수축 시작일로 둔다. 최근 21시장일에 P1형 양봉이 없고 가격이 관측된 날에서 같은 날짜·시장·직전 20일 거래대금 삼분위의 비수축일을 대조군으로 사용한다. 매칭 표는 종목일 기준, 매매 표는 종목별 60시장일 비중첩 후보만 사용한다.
- 돌파 이력이 **20일 평가 완결·동일 선에서 20일 비중첩으로 8건 이상**인 경우에만 그 종목의 선을 선택한다. 점수는 돌파 이후 첫 P1 20일 발생률에 공통 사전표본 4건·성공 2건을 더한 비율이다. 동률은 더 큰 표본과 이름순으로 결정한다. 과거 판정 마감일이 선택일 전인 사례만 사용한다. 2025~2026년은 2024년 말 기준 선택을 그대로 사용한다. 선택 불가 시 공통 BB40 상단으로 되돌아간다. 공통 엔벨로프 중심선 진입을 별도 비교한다.
- 수축 다음 시가, P1 다음 시가, P3 다음 시가, 지정선 돌파 다음 시가를 공통 D0+60 만기에서 비교한다. P1 및 지정선 돌파는 D0 이후 최대 20일 창을 사용한다. 지정선은 D0 포함, P1은 D+1부터다. +10% 익절, 기본 −5% 손절, 비용 0.25%p, 당일 손절·익절 동시 도달 시 손절 우선, 갭은 시가를 사용한다. 거래 없음은 기회당 평균에서 0이며, 불완전 경로는 별도 표에 둔다. 놓친 +5%·+10%는 최초 시가 대비 실제 진입 전 고가 또는 미진입 시 만기까지의 고가 도달이다.
- P2의 저가가 해당 선에서 0.5 ATR 이내이고 종가가 위였는지, 그 후 P3까지 종가 이탈이 없었는지 따로 기록한다. 지원선 선택은 P1+40까지 완료하고 40일 비중첩한 과거 사례 8건이 필요하다. P3 매수에서 기준선 이탈은 종가 확인 후 다음 시가, P3 시점에 알려진 P1 이후 눌림 최저가 이탈은 장중 손절이다. 선택된 선이 P2/P3 조건을 충족하지 않으면 기본 −5%를 사용한다.
- 선 겹침은 돌파선에서 0.5 ATR 이내에 다른 기간 계열이 있는지로 판단한다. 같은 기간의 설정 두 개는 한 계열로 센다. 선행 순서 표는 P1 이전 20시장일에 두 선이 나타난 순서를 비교하고, P1이 없는 경우를 포함한 전방 발생률은 돌파 결과표에서 따로 계산한다.

## GitHub 업로드

ZIP에서 `research_projects/blue20_effective_lines_research/`와 `.github/workflows/stockhunter_blue20_effective_lines_research_only.yml`을 같은 경로에 업로드한다. 루트의 YML은 같은 파일의 복사본이다. 기본 브랜치 반영 후 **Actions → BLUE20 Effective Lines and Pullback (RESEARCH_ONLY) → Run workflow**를 실행한다. 결과 이름은 **BLUE20_EFFECTIVE_LINES_RESEARCH_ONLY**다. 기존 공통 워크플로와 실전 파일을 그대로 보존하는 별도 작업이다.
