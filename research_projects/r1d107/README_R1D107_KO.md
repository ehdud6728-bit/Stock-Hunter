# Stock-Hunter R1-D107 | 의미 있는 추세선·수렴 품질 검증 (RESEARCH_ONLY)

## 핵심 질문

R1-D106이 생성한 **19,724개 추세선 및 17,062개 수렴 형상 후보** 중 어떤 선이 실제로 의미 있는 구조였는가?
단순히 '그렸을 때 보기 좋은 선'이나 돌파 후 수익이 좋았던 선을 사후 선택하지 않고, **그 날짜에 알 수 있던 정보만으로** 설명력을 점검한다.

## 입력과 보존 원칙

- 기본 연구 자료는 기존 R1-D97의 해시 고정 KRX OHLCV 원본 3종목과, **같은 GitHub Actions 실행 안에서 생성된 R1-D106** 출력 파일이다.
- R1-D106의 `R1D106_ALL_IMMUTABLE_LINES.csv` 및 `R1D106_ALL_TRIANGLE_CANDIDATES_PIT.csv`를 읽기 전용으로 사용한다. 작업 전후 SHA256이 같은지 검사한다.
- R1-D96~D106 원본과 과거 WATCH는 삭제·재작성하지 않는다. LIVE 검색/매매에 연결하지 않는다.
- `study: r1d107` 실행은 R1-D105→R1-D106→R1-D107을 연속 실행한다. 새로운 workflow YML은 생성하지 않고 기존 공유 YML만 갱신한다.

## 추세선 평가 기준 (가설; 매수 확률이나 승률이 아님)

1. 양봉·음봉 몸통 및 고가·저가 피벗 기준점의 강도: `anchor_strength`.
2. 두 기준점의 간격과 두 점 사이 **기존 가격의 관통 횟수**: `penetrations_1p2pct`.
3. **두 번째 기준점 확정 이후** 발생한 접촉과 선을 존중한 종가, 반대편에서 마감한 횟수.
4. 극단적으로 가파른 선에는 진단상 감점. 마감 당일 선까지 거리가 0%라고 신뢰도를 높이지 않음.
5. 가까운 수준과 유사한 기울기의 다수 선은 **표시용으로만 묶기**. R1-D106 원본 라인/이벤트에 손대지 않는다.

`quality_diagnostic_0_100`는 임의의 고정 진단 점수이며, **투자 성공 가능성을 뜻하는 0~100%가 아니다**. 상승 종목의 미래 수익률로 가중치·문턱값을 최적화하지 않았다. 10거래일 간격 자동 대표선 추적 결과에도 표본 외 검증이 필요하다.

## 삼각수렴·쐐기 판정 기준

- 두 선이 **모두 알려진 최초 날짜** 이전에 수렴이 발견됐다고 기록하지 않는다.
- `price_position_at_first_known`가 이미 상단 위라면 **사전 삼각수렴 돌파**로 소급하지 않는다.
- 최초 확인 이후 이전 두 거래일 이상 종가가 수렴대 **안에 있었던 경우에만** 새로운 돌파를 점검한다.
- 상단 종가 돌파 강도 0.4% 이상을 연구용 기준으로 사용한다. 꼭짓점까지 **최소 2거래일** 남았어야 새 돌파로 분류한다.
- 꼭짓점 이후 무한히 하락하는 상단선 위에 있다고 성공적인 지지라고 평가하지 않는다. 사후 평가는 **꼭짓점 이전 기간과 이후 20거래일 성과**를 분리한다.
- 연구 부담을 제한하기 위해 최초 확정일과 이후 +1/+2/+3/+5/+10/+15/+20일의 추적 시점에서만 삼각수렴 새 돌파를 검사한다. **매 거래일 모든 돌파를 완전 탐지하는 연구가 아니다.**
