# ENV10·ENV20 고정 300건의 D0 이전 차트·거래량 맥락 점검 (R4)

운영: **RESEARCH_ONLY**. 기존 LIVE·SEARCH·WATCH, 종목 검색식, 주문·청산 및 다른 연구 소스는 변경하지 않는다.

## 목적 및 구분

- R2·R3에서 고정한 동일한 300개 사건과 ENV10_ONLY 37 / ENV20_BOTH 3 / NO_TOUCH 257 / UNKNOWN 3 그룹을 그대로 사용한다.
- 이 연구는 하단 엔벨로프 **터치 당일의 맥락**만 기술한다. 추세선·전고점 **상향 돌파** 연구나 새 전략 개발과 혼동하지 않는다.
- 추세선 돌파 연구의 필수 선행 검증인 삼성SDI 2026-11-02 선과 2026-11-06 돌파선 동일성은 **아직 미완료**다.

## 계산 규칙

| 항목 | 시점·계산 |
| --- | --- |
| D0 거래량 / 평균 | D0 거래량 ÷ 정확히 D-20..D-1 20개 유효 봉 평균 거래량. 당일 제외 |
| D0 거래대금 / 평균 | 동일 기준 20개 봉의 실제 제공 거래대금 평균. 종가×거래량 대체 금지 |

| 파동·눌림 대리값 | D-60..D-3 구간에서 종가 기준 최대 상승 저점→고점이 15% 이상이고 D-1 종가가 상승폭의 20~80%를 반납한 경우. 실제 파동 확정이나 매수 신호가 아님 |

### 결측 처리

- 기간 전체 유효 일봉이 없으면 해당 특징의 상태를 `UNKNOWN`으로 남긴다. 0이나 직전 봉으로 채우지 않는다.
- 20일 분모가 0이거나 거래량·거래대금 값이 결측/비정상이면 비율을 만들지 않는다.
- 기간을 만족한 사건에만 수치가 기록된다. 그룹의 알려진 표본 수와 결측 수를 항상 함께 보고한다.
- 모든 D0 특징은 D0 마감 시점까지의 값만 본다. D+1 이후 결과를 기준으로 신호를 바꾸지 않는다.
