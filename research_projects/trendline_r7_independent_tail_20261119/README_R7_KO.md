# Stock-Hunter R7 — 비중복 추세선 돌파·손실 꼬리 검증

연구일: 2026-11-19 · `RESEARCH_ONLY` · **실전 매도 규칙·수익성 입증 아님**.

## 첨부된 R7 화면과 이번 코드의 관계

사용자가 전달한 R7 예비 화면에는 90건의 비중복 표본과 다음 여섯 가지 방식의 평균 손익이 보고되었다.

| 방식 | 화면의 **예비 평균** (총비용 0.2%p 가정) |
| --- | ---: |
| D+20 보유 | −1.86% |
| 초기 3ATR 손절 | −1.58% |
| ATR 추적손절 | −0.86% |
| 전저점·추세선 이탈 | −1.28% |
| 거래량 동반 하락 | −0.93% |
| ATR·거래량·가격 구조 2개 이상 | −0.92% |

**주의: 화면에는 ATR 계산 방식, 추적 기준, 거래량 임계값, 조합 판정의 실제 코드가 없다.**
이번 연구는 R5/R6의 보존 원장으로 **94/90 분모를 재현**하고, 새 규칙을 아래와 같이 *독립적으로 명시해 구현*한다. 화면의 규칙·수익률을 정확히 재현했다고 주장하지 않는다. 일치하지 않는 값이 나오더라도 결과를 임의로 맞추지 않는다.

## 고정 분모: 506 → 368 → 94 → 90

1. R5 R116 원본 상단 추세선 돌파 506개 선 사건을 그대로 재생. 삼성SDI 006400, 디오 039840, 롯데하이마트 071840의 3종목만 대상.
2. 동일 종목·D0에 중복 선이 있다면 R6의 사전 순위 `MEDIUM → LONG → SHORT`로 고유 368건 확정. 미래 수익률 기준으로 선택하지 않는다.
3. 종목별 시계열에서 가장 이른 D0를 선택한 뒤, 다음 D0는 **직전 선택 D0보다 인덱스 21 이상**일 때만 선택한다. 20거래일 결과 관측 구간이 겹치지 않는 **94건**. 누락된 미래 결과나 매도 규칙 성과를 읽고 선택하지 않는다.
4. 이 94건 중 D+20 미완료 1건, 원래 추세선 기하 미상 3건은 동일 조건의 전 전략 비교에서 제외(90건). 미상을 0%로 대체하지 않는다. 94건 원장에는 계속 남긴다.

**94/90 표본은 독립적인 투자 실험 90개가 아니다.** 3종목의 여러 시기 사건이 반복되고, 시장 동조·기간 선택·생존편향이 남는다. 단순 사건 중첩을 줄인 기술통계다.

## 신규 매도 규칙: 이번 코드에서 사전 명시한 재현 가능한 가정

모두 D+1 시가에 가상 매수하고 D+20 안에 청산한다. 왕복 총비용은 20bp. 실제 주문 체결은 재현하지 않는다.

| 코드 | 정의 |
| --- | --- |
| `TIME_D20` | D+20 종가 청산. R6과 건별 값 일치 확인 |
| `INITIAL_3ATR_STOP` | D0 종가까지 확정된 마지막 14개 TR의 **산술평균 ATR14** ×3을 진입가에서 뺀 고정 손절선. 갭 하락은 손절선보다 불리한 시가 체결 |
| `ATR_TRAIL_3` | 초기 3ATR 손절선부터, **전일까지 완성된** D+1 이후 최고 일중고가−전일까지 확정된 ATR14×3으로 손절선을 올리되 낮추지 않는다. 당일 고가를 그날 손절선에 반영 금지 |
| `STRUCTURE_NEXT_OPEN` | D0 이전 20개 봉의 **고정 저가** 또는 돌파 당시 확정한 **동일 원본 추세선**(0.4% 버퍼) 아래로 종가 마감하면 다음 거래일 시가 청산 |
| `VOLUME_DOWN_NEXT_OPEN` | D+h 종가가 전 거래일 종가보다 낮고, D+h 거래량이 **직전 20일 평균의 1.5배 이상**이면 다음 날 시가 청산 |
| `TWO_OF_THREE_NEXT_OPEN` | ① 전일까지 최고 고가−3ATR 아래 종가 ② 하락+1.5배 거래량 ③ 고정 전저점/동일선 종가 재이탈, 세 조건 중 **완료된 같은 날 종가 기준 2개 이상**이면 다음 날 시가 청산 |

손절은 일봉의 저가 접촉으로만 확인하므로 실제 주문 슬리피지·체결 가능성·고저 발생 순서는 모른다. D+20 이후 가격은 매도 결정에 쓰지 않는다. 임계값 3ATR·1.5배·0.4%는 이 연구에서 고정한 연구용 대리 정의로, 성과에 맞춰 최적화하지 않는다.

## 이번 검증의 핵심

- **평균과 중앙값**이 모두 개선되는지, 최악 10% 평균·5/10분위·−10% 이하 손실 횟수가 어떻게 달라지는지.
- 같은 90개 사건을 사용한 **건별 차이**와 개선/악화 건수, D+20에는 손실이지만 조기 청산으로 완화된 건수 및 반대로 D+20 수익을 조기 손절로 놓친 건수.
- 3종목별·연도별 표본 수와 수치의 민감도. 종목별 분산을 무시한 유의성 주장 금지.
- `R7_NONOVERLAP_RULES_FULL_LEDGER.csv`에 비교 불가능 4건 포함 모든 94건×6규칙의 이유·청산일·비용 차감 손익 보존.
- `R7_TAIL_DISTRIBUTION_SUMMARY.json`에 전 규칙의 꼬리 지표, 대응 차이, 미상 사유, 모든 미인증 게이트를 기록.
