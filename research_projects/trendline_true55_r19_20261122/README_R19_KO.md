# R19 · 실제 직전 55거래일 최고가 돌파 검증 (RESEARCH_ONLY)

> 연구 전용. 전략 승인, 실거래 수익률, 실시간 주문·검색·관찰 로직 변경을 의미하지 않습니다.

## 왜 이 실험인가

기존 R116 추세선 돌파는 **직전 55거래일의 최고가 돌파**와 다른 신호입니다. 55일 신고가의 진입·손절·익절 문제를 직접 연구하기 위해 두 사건 집합을 분리했습니다. -5% 고정 손절 또는 +10% 고정 익절 같은 임의 수치를 정답으로 사용하지 않습니다.

## 사전 정의된 시점과 규칙

1. D0 확정 종가가 **D0 이전 55거래일의 최고 고가**보다 **엄격하게 높음**. D0 당일 고가는 기준에서 제외.
2. 같은 종목의 신호는 60거래일 간격으로만 독립 취급(후일 성과 확인 전에 중복 제거).
3. D0 종가를 본 후 매수했다고 소급하지 않음. D+1 시가가 D0에서 고정한 직전 55일 최고가 위일 때 **D+1 시가 진입**으로 평가.
4. D+60까지 경로가 없는 미완료 사례는 제외하고 건수를 별도로 공개.
5. 매도는 세 가지 **가격 구조의 종가 이탈 → 다음 시가 청산**: D0 신호봉 저가, 직전 5봉 저가, 직전 10봉 저가. 구조가 유지되면 D+60 종가 기준 청산. 왕복 거래비용 0.2% 차감.
6. 기간 중 최고 수익 가능폭(MFE), 최저 손실 가능폭(MAE), 최고가 날짜는 **사후 설명 지표**일 뿐 실전 익절 신호가 아님.
7. R18 6개 D0 특성의 큰 손실 위험 분류기를 2021~2023년의 기존 R116 425건 또는 실제 55일 돌파 90건에서 각각 학습하고, 두 버전을 2024~2025년 실제 55일 돌파 59건에 이전(transfer). 위험 정의(학습 손익 하위 10%)와 경고 임계값(학습 점수 상위 25%)은 **이전 기간에서만** 결정하며 테스트 구간을 보고 조정하지 않음.
