# R1-D117 — 원본 추세선 기하학 보존 × 안정적 활성선 × 돌파 후 역할 감시 (RESEARCH_ONLY)

- **목적:** R1-D116에서 빈번한 신규선 생성/교체를 줄이는 상태관리 가설을 R1-D112와 독립적으로 비교.
- **기존 연구 보존:** R1-D111 원본 선, R1-D112 활성선, R1-D116 대조군, R1-D113~D115 구조 연구, LIVE/SEARCH/WATCH 미변경.
- **후보 생성:** R1-D111 53,998개 원본 후보를 다시 생성하거나 사람이 지정한 추세선을 학습하지 않음. R1-D116의 종가시점 Top3·제안선만 사용.
- **R117 관리 규칙:** (1) 확정 다음 거래일 이후 활성화 (2) 유효선은 유지, 조건에 맞는 큰 새 변곡에만 교체 (3) 종가 2회 연속 돌파/이탈 시 종료 (4) 종료한 선 ID 재활성화 금지 (5) 새 후보는 활성선과 별도로 WATCH 표시 (6) 돌파한 기존 선의 첫/두 번째 재접촉·실패를 원본 실제 OHLCV로 사후 관찰.
- **선 정확도:** `v1 + m × (idx - i1)`을 사용하고 두 기준점의 원본 가격과 수학적으로 일치하는지 검사. 퍼센트 기울기로 다시 근사하지 않음.
- **시점:** t일 상태는 t일 **종가 이후**에만 사용 가능. 확정 피벗이 없는 경우 과거 사용 불가. 사후 관찰은 선택에 사용하지 않음.
- **실제 로컬 실증(일부 원본 OHLCV만 사용):** R111/R112/R116의 전체 이력(3종목·4방법·58,008일별 lane, 원본 후보 53,998개)으로 선택을 재생했고, 실제 가격 차트는 R109에서 기록된 연속 사례 구간의 실제 KRX OHLCV만 사용. 추세선 생성/교체 3,661건(기존 R116은 6,991건), 그러나 디오 양봉선은 활성선에 채택되지 않고 WATCH에만 등장. 롯데하이마트 양봉선은 활성선으로 채택. **R117의 GitHub 전체 OHLCV 결과 및 역할 재접촉은 아직 검증 전**.
- **고정 연구용 값:** 종가 2회, 0.4% 선밖, 규모별 보존·거리·갱신 여유. 최적화된 투자 규칙이나 승률 아님.
