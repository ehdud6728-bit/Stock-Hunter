# Stock-Hunter R7: ATR·거래량·전고점/전저점 복합 매도 연구 (RESEARCH_ONLY)

## 목적

R6의 D+1 시가 진입→D+20 종가 보유 성과만으로 적절한 매도 시점을 알 수 없습니다.
R7은 가격 구조·거래량·ATR을 각각 또는 복합적으로 활용한 **인과적 실행 가능성 진단**입니다.
R5의 3개 종목·506개 추세선 사건 / 368개 고유 종목-날짜를 고정한 R6
소스 SHA-256을 재검사합니다. 3개 종목은 임의로 고른 사례이지 전체시장/OOS 모집단이 아닙니다.

## 어떤 정보가 언제 확정되는가?

- D0 종가 기준: Wilder ATR(14), D0 거래량/거래대금과 D-20일 평균 비율,
  사전에 확인된 20일/60일 고가·저가, 원래 R5 저항선.
- D+h 종가 기준: 이전 10개 **완성된** 봉의 저가 이탈, 이전 20일 평균 대비
  당일 거래량 1.5배 이상 + 당일 음봉/전일보다 종가 하락, 원래 돌파선
  재이탈, 전일까지의 고점·ATR에 비춘 가격 약화.
- 종가 조건은 반드시 **D+h 마감 후** 관찰하며 실제 모의 청산은
  **D+h+1 시가**. D+20 이후는 관측하지 않습니다.
- ATR 초기손절·샹들리에의 당일 손절가는 **장 시작 전**까지의 고가·ATR로만
  설정합니다. 하향 갭이면 사전 손절가보다 불리한 시가로 체결했다고 가정.
- 일봉 가격/거래량만으로 실제 가격대별 거래량(POC/매물대), 매수·매도
  주도 체결량, 장중 고가·저가 발생 순서를 알 수 없습니다. 미상으로 표시합니다.

## 사전 고정 비교군 (결과로 매개변수 선택 금지)

| 이름 | 설명 |
| --- | --- |
| R6_TIME_D20_BASELINE | R6과 일치하는 D+20 종가 |
| ATR_INITIAL_3 | D+1 진입가 − ATR14(D0)×3을 최초 한 번 고정 |
| ATR_CHANDELIER_3 | 이전까지의 최고가 − 이전 ATR14×3, 이전 손절가보다 낮추지 않음 |
| STRUCTURE_PRIOR10_CLOSE_NEXT_OPEN | 당일 종가가 이전 10봉 저가 또는 사전 확정 저항선 밑으로 이탈 시 다음 날 시가 |
| VOLUME_DOWN_1_5_CLOSE_NEXT_OPEN | 이전 20일 평균 대비 1.5배 이상 거래량 + 음봉 + 전일보다 종가 하락 시 다음 날 시가 |
| CONFLUENCE_2OF3_CLOSE_NEXT_OPEN | 구조 이탈 / 대량거래 음봉 / 이전 고점 대비 2.5ATR 약화 중 두 조건 이상 시 다음 날 시가 |

진입은 D+1 시가, 최대 보유 20거래일, 조건 미발동 D+20 종가,
총비용 20bps. 예시 배수는 최적값이나 추천값으로 해석하면 안 됩니다.

## 중복 사건과 산출물

같은 종목에서 20거래일 이내 반복 발생한 신호는 독립 시행이 아닙니다.
그래서 R6의 대표 368건 외에 **종목별 최초 발생일부터 20거래일
겹침을 배제한 보수적 사건 집합**을 독립 표로 함께 분석합니다.
같은 종목·날짜의 선 대표는 R6에서 미리 정한 MEDIUM→LONG→SHORT 순위입니다.
또한 종목별·연도별 결과를 분리하고 결측은 0%가 아닌 UNKNOWN으로 둡니다.
특히 R6 기준군의 완비 363건과 신규 지표 완비 건수가 다르므로
각 모델의 효과는 **같은 종목-날짜에서 모두 계산 가능한 표본만 비교**한
쌍별 차이를 따로 산출합니다. 단, 종목 간 시장 동조성은 여전히 존재합니다.
