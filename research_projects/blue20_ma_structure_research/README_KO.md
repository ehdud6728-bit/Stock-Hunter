# BLUE20 60/112/224 이동평균선과 실제 차트 성공·실패 연구 (RESEARCH_ONLY)

## 연구 목적
기존 500종목 2023~2024년 BLUE20/RSI/Slow 연구의 **명확한 몸통 돌파, Wilder RSI14/SMA9 D0~D+10 골든크로스 후 다음 거래일 시가 매수** 1,804개 사건을 동일하게 재현하고, 60/112/224일선의 지위·정배열/역배열·기울기·수렴 여부를 **D0와 RSI 골든크로스일 각각** 분리하여 분석합니다.

기존 `wave_ma224_context`는 돌파일이 아니라 이전 파동 고점에서 MA224를 판정했던 지표이므로, 이번 신규 연구에서는 그것을 D0 MA224 여부로 재사용하지 않습니다.

## 실제 원본과 신호 정의
- 과거 일봉: 기존 `research_projects/r1d118/auto_data.py`가 2022년 말 시총 기준으로 고정한 500종목의 2022~2024년 원본입니다. 원본 경로·SHA는 기존 R118 500종목 매니페스트의 SHA256으로 검사합니다. KRX에서 직접 실시간 수신한 원본이 아니라 FinanceData의 보관용 자료입니다.
- 돌파 사건: 기존 `research_projects/blue20_rsi_delay_research`가 생성하는 2023~2024년 8,939개 원본 사건 중 Wilder/SMA9, 명확한 몸통, RSI GC D0~D+10, 실제 진입 가능 사건만 채택한 1,804개입니다. 1,804가 아니라면 연구는 오류로 중단합니다.
- 수익성: 과거 원장의 D+20, 목표 +10%, 손절 -5%, 손절 우선, 왕복 비용 -0.25%p, RSI 확인 **다음 거래일 시가 진입**이라는 원래 정의를 유지합니다. 이후 상승 고점(MFE)은 실현수익이 아니라 사후 최대 상승률입니다.
- 이평선: 수정주가·공식 HTS 계산 방식과 동치라는 주장은 하지 않습니다. 종가 단순이동평균 SMA(5,20,60,112,224)를 기준으로 5·10·20일의 이동평균선 기울기를 `% = 100 × (MA_t/MA_{t-k} - 1)`로 정합니다. MA224 준비기간이 없으면 UNKNOWN으로 남깁니다.
- 차트: 종목별 검증된 일봉 **시가·고가·저가·종가의 실제 캔들** + MA5/20/60/112/224 + SHIFT(BB20 2σ,26) 원형 점선 + 거래량 + RSI Wilder14/SMA9 + Slow(14,3,3). D0/RSI GC/다음날 매수/청산선과 파동 고점·눌림 저점을 표시합니다.

## 실제로 분석할 분류
1. GC 또는 D0 종가가 60/112/224일선 위/아래인지
2. MA60 > MA112 > MA224 정배열, MA60 < MA112 < MA224 역배열, MA60이 MA112를 올라섰으나 아직 MA112 < MA224인 초기 전환
3. MA60·112·224 각각의 5·10·20일 변화율: 상승(+0.1% 초과), 하락(-0.1% 미만), 보합/미확인
4. 60·112일선의 간격이 20일 전보다 축소되었는지, 종가가 60/112일선 돌파했는지
5. 기존 1차 파동 눌림, 시장 국면, Slow 상태와 결합했을 때 익절률·손절률·실현순손익·D+20 고점(MFE) 비교
6. 2023/2024년 각각의 방향 및 표본 검증. 우연에 의한 조합 탐색 편향 주의

### 분석 정보의 시간 경계
- 신호는 RSI GC 다음날 시가 진입. 진입 후 각 거래일 **종가 확정 후** 양봉/음봉, 실체/꼬리 비중, 장악형, 도지, 종가 위치, 거래량·거래대금 상대배율을 계산합니다. 해당 날짜의 캔들 완성 형태를 당일 장중 손절 회피 근거로 사용하지 않습니다.
- `amount_ratio20 = 당일 거래대금 / 직전 20거래일 거래대금 평균`이며 **당일을 평균 분모에서 제외**합니다. `volume_ratio20`도 동일.
- 캔들 형태: `BIG_BULL`, `BIG_BEAR`, `LONG_LOWER_WICK`, `LONG_UPPER_WICK`, `DOJI`, `INSIDE_BAR`, `BULL_ENGULF`, `BEAR_ENGULF`, `OTHER`. 분류 우선순위는 코드에서 고정하고 겹치는 형태는 개별 boolean으로 보관합니다.
- `HEAVY_DOWN_PROXY`: 전일 종가 대비 하락, 거래대금배율 >=1.8, 일봉 종가가 고저폭 하위 30% 수준. 매도세 확정이 아니라 하락과 거래활동의 동시 발생.
- `QUIET_DOWN_PROXY`: 전일 종가 대비 하락, 거래대금배율 <=0.7. 기관의 매집이나 바닥 확정은 아님.
- `LOWER_WICK_HIGH_TURNOVER`: 아래꼬리가 길고 높은 거래활동; 역시 매수 주체를 확정하지 않음.
- 주황 상단 / 파란 하단 = 기존 기준인 `SHIFT(BB20 ± 2σ,26)`. `shifted_band_squeeze`는 과거 밴드의 지연 표시 수렴으로 **당일 변동성 압축과 동일하다고 주장하지 않음**.
- 60/112/224일선 값과 기울기, 두 점선의 폭, 하단선 회복/이탈, 상단선 몸통 돌파를 일봉별로 함께 기록합니다.
- 사건별 전체 진입 후 ~ 원래 돌파일 D+20을 보유 중/기존 손절 **이후 단순 관찰**로 나누어 기록합니다. 손절 뒤 상단 돌파는 `FUTURE_OBSERVATION_ONLY`로 따로 보관하고 이전일 필터로 쓰지 않습니다.

### 두 개의 청산정책 (탐색 용도, 실전 지시 아님)
- A: 기존 +10% 목표, -5% 손절(갭 시 시가 체결, 같은 일봉 동시 도달 시 손절 우선), D0+20 기한, 비용 -0.25%p. **1,804건 원래 결과와 한 건씩 일치하지 않으면 실행 중단합니다.**
- B: 위 조건에서 전일 EOD에 사전 정의된 밴드 수렴 + 하단선 위 종가 + 거래대금 과열 부재 + 60일선 양의 기울기/아래꼬리가 존재할 때만 다음날 -5% 소프트 스톱 유예. **별도 -12% 하드 스톱**, 구조 붕괴 + 많은 거래활동은 다음날 시가 청산. +10% 목표, D0+20 기한은 동일. 이 정책은 A보다 손실을 더 키울 수 있습니다. -12% 아래 갭 출발은 시가 체결로 더 큰 손실이 가능합니다. A/B 위험이 동등하지 않으므로 초과수익을 안전성 우위로 해석 금지.
- 모든 조건은 미리 코딩한 **탐색적 가설**일 뿐 적합도·과최적화·2025~2026 독립 검증 전에는 실전에 채택할 수 없습니다.

### 실수급 자료의 진실성
`volume`과 `amount`만으로 **외국인/기관/개인의 실제 순매수는 절대로 알 수 없습니다.**
원본에는 투자주체별 수급과 매수/매도 체결강도가 들어 있지 않으므로 기본값은 `investor_pit_status=PIT_MISSING`입니다.
독립적으로 확보한 과거 투자자별 순매수자료가 있는 경우 `--investor-pit FILE.csv` 인자를 통해
`code,date,known_at,foreign_net_krw,institution_net_krw,retail_net_krw,source_id`
형식을 선택적으로 읽습니다. `known_at`은 해당 자료를 **그날 종료 시점까지 알 수 있었던 최초 날짜**입니다. 알려지기 전에는 결코 당일 신호에 사용하지 않으며, 제공된 투자자별 숫자의 진실성을 이 코드가 자동으로 인증해주는 것은 아닙니다. 원천 링크, 단위, 수정 이력은 별도 감사가 필요합니다.
